# 簡介

![附加單元 1 縮圖](https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/bonus-unit1/thumbnail.jpg)

歡迎來到第一個**附加單元**！你將學習**微調大型語言模型（LLM），讓它具備函式呼叫能力**。

對 LLM 而言，函式呼叫正迅速成為一項*必備*技術。

我們在第 1 單元只依靠 prompt 來引導模型；函式呼叫則讓模型在**訓練階段就學會採取行動、解讀觀察結果**，使 AI 更穩健。

> **什麼時候適合學習這個附加單元？**
>
> 本單元為**選修**，內容比第 1 單元進階。你可以現在開始，也可以等透過課程累積更多知識後再回來學習。
>  
> 不用擔心，本單元會提供所需的資訊。即使你還不了解微調的內部原理，我們也會帶你認識微調函式呼叫模型的每個核心概念。

如果具備以下知識，學習本單元會更順利：

1. 知道如何使用 Transformers 微調 LLM。如果還不熟悉，請[參考這份教學](https://huggingface.co/learn/nlp-course/chapter3/1?fw=pt)。

2. 知道如何使用 `SFTTrainer` 微調模型。詳情請[參閱這份文件](https://huggingface.co/learn/nlp-course/en/chapter11/1)。

## 你將學到什麼

1. **函式呼叫（Function Calling）**  
   現代 LLM 如何組織對話，讓模型能夠觸發**工具**。

2. **LoRA（低秩適應）**  
   一種**輕量、高效率**的微調方法，能減少運算與儲存需求。LoRA 讓大型模型的訓練*更快、成本更低，也更容易*部署。

3. **函式呼叫模型中的思考 → 行動 → 觀察循環**  
   以簡單而強大的方式，組織模型決定何時及如何呼叫函式、追蹤中間步驟，以及解讀外部工具或 API 結果的流程。

4. **新的特殊 token**  
   我們會介紹**特殊標記**，幫助模型區分：
   - 內部的「思維鏈」推理  
   - 對外發出的函式呼叫  
   - 外部工具回傳的回應
