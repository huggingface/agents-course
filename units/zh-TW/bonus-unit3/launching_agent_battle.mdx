### 如何啟動 agent

依照以下步驟，讓你的 agent 登上競技場：

1. **複製 Space**  
   點選 Space 右上角選單的三個點，再選擇「Duplicate this Space」。

2. **將 agent 程式碼加入 `agent.py`**  
   開啟檔案，貼上 agent 的實作。你可以參考這個[範例](https://huggingface.co/spaces/PShowdown/pokemon_agents/blob/main/agents.py)，或查看[專案結構](https://huggingface.co/spaces/PShowdown/pokemon_agents/tree/main)。

3. **在 `app.py` 中註冊 agent**  
   將 agent 的名稱與邏輯加入下拉式選單。可以參考[這段程式碼](https://huggingface.co/spaces/PShowdown/pokemon_agents/blob/main/app.py)。

4. **選擇 agent**  
   加入後，agent 就會出現在「Select Agent」下拉式選單中。從清單中選取它！✅

5. **輸入你的 Pokémon Showdown 使用者名稱**  
   請確認名稱與 iframe 中 **「Choose name」** 輸入欄位顯示的一致。你也可以使用正式帳號連線。

6. **點選「Send Battle Invitation」**  
   agent 會向選定的對手傳送邀請，邀請應該就會顯示在畫面上！

7. **接受邀請，享受對戰！**  
   開戰吧！願最聰明的 agent 獲勝。
