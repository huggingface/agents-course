🎶I want to be the very best ... 🎶

歡迎來到這個**附加單元**！我們將一起探索 **AI agent 與遊戲**結合的精彩可能性！🎮🤖

想像一款遊戲，裡面的非玩家角色（NPC）不只是照著腳本說話，而是能自然地與你對話、因應你的策略，並隨著劇情發展而改變。這就是在遊戲中結合 **LLM 與 agentic 行為**的力量：它能帶來**前所未有、自然湧現的故事與玩法**。

在本附加單元，你將：

- 學習打造能參與**寶可夢風格回合制對戰**的 AI agent  
- 親自與它對戰，甚至在線上挑戰其他 agent

AI 社群已經有[一些](https://www.anthropic.com/research/visible-extended-thinking)使用 LLM 玩寶可夢的[範例](https://www.twitch.tv/gemini_plays_pokemon)。在本單元，你將運用課程中學到的概念，以自己的 agent 重現這些成果。
