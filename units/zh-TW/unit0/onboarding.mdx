### 步驟 5：使用 Ollama 在本機執行模型（遇到額度限制時適用）

1. **安裝 Ollama**

    請依照<a href="https://ollama.com/download" target="_blank">這裡的官方說明</a>安裝。

2. **將模型下載到本機**

    ```bash
    ollama pull qwen2:7b
    ```

    這裡下載的是 <a href="https://ollama.com/library/qwen2:7b" target="_blank">qwen2:7b 模型</a>。你可以到 <a href="https://ollama.com/search" target="_blank">Ollama 網站</a>尋找更多模型。

3. **在背景啟動 Ollama（使用一個終端機）**
    ``` bash
    ollama serve
    ``` 

    如果遇到「listen tcp 127.0.0.1:11434: bind: address already in use」錯誤，可以使用 `sudo lsof -i :11434` 指令，找出目前使用這個連接埠的行程 ID（PID）。如果該行程是 `ollama`，很可能是前面的安裝指令碼已啟動 Ollama 服務，你就可以跳過這個啟動 Ollama 的指令。

4. **以 `LiteLLMModel` 取代 `InferenceClientModel`**

   若要在 `smolagents` 中使用 `LiteLLMModel` 模組，可以執行 `pip` 指令安裝。

``` bash
    pip install 'smolagents[litellm]'
```

``` python
    from smolagents import LiteLLMModel

    model = LiteLLMModel(
        model_id="ollama_chat/qwen2:7b",  # Or try other Ollama-supported models
        api_base="http://127.0.0.1:11434",  # Default Ollama local server
        num_ctx=8192,
    )
```

5. **為什麼這樣可行？**
- Ollama 會透過 `http://localhost:11434` 上與 OpenAI 相容的 API，在本機提供模型服務。
- `LiteLLMModel` 能與任何支援 OpenAI chat/completion API 格式的模型通訊。
- 因此，只要將 `InferenceClientModel` 換成 `LiteLLMModel`，就能直接使用，不需要更動其他程式碼。
