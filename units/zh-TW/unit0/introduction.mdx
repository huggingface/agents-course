## 這門課程能學到什麼？ [[expect]]

在這門課程中，你將：

- 📖 從**理論、設計與實作**學習 AI agent。
- 🧑‍💻 學會**使用成熟的 AI agent 函式庫**，例如 [smolagents](https://huggingface.co/docs/smolagents/en/index)、[LlamaIndex](https://www.llamaindex.ai/) 與 [LangGraph](https://langchain-ai.github.io/langgraph/)。
- 💾 在 Hugging Face Hub 上**分享你的 agent**，並探索社群建立的 agent。
- 🏆 參加挑戰，**比較你的 agent 與其他同學的 agent 表現**。
- 🎓 完成作業，**取得結業證書**。

還有更多內容等你探索！

課程結束時，你將了解 **agent 如何運作，以及如何使用最新的函式庫與工具建置自己的 agent**。

別忘了 **<a href="https://bit.ly/hf-learn-agents">報名課程！</a>**

（我們尊重你的隱私。收集電子郵件地址是為了**在各單元發布時寄送連結，並提供挑戰活動與課程更新資訊**。）

## 課程如何進行？ [[course-look-like]]

課程包含：

- *基礎單元*：學習 agent 的**理論概念**。
- *實作*：學習**使用成熟的 AI agent 函式庫**，在不同環境中訓練 agent。這些實作會透過預先設定好環境的 **Hugging Face Spaces** 進行。
- *應用案例作業*：運用所學概念，解決你自行選擇的實際問題。
- *挑戰賽*：讓你的 agent 與其他 agent 一較高下。你也可以在[排行榜](https://huggingface.co/spaces/agents-course/Students_leaderboard)比較各個 agent 的表現。

**這門課程會隨著你的回饋與貢獻持續成長！** 歡迎[在 GitHub 提出 issue 與 PR](https://github.com/huggingface/agents-course)，並參與 Discord 伺服器中的討論。

完成課程後，也歡迎[👉 填寫這份表單](https://docs.google.com/forms/d/e/1FAIpQLSe9VaONn0eglax0uTwi29rIn4tM7H2sYmmybmG5jJNlE5v0xA/viewform?usp=dialog)提供回饋。

## 課程大綱有哪些內容？ [[syllabus]]

以下是**課程的整體大綱**，每個單元發布時會提供更詳細的主題清單。

| 章節 | 主題 | 說明 |
| :---- | :---- | :---- |
| 0 | 入門準備 | 準備課程會用到的工具與平台。 |
| 1 | Agent 基礎 | 說明工具、思考、行動、觀察及其格式；介紹 LLM、訊息、特殊 token 與對話範本，並示範以 Python 函式作為工具的簡單案例。 |
| 2 | 框架 | 了解 smolagents、LangGraph、LLamaIndex 等常用函式庫如何實作這些基礎概念。 |
| 3 | 應用案例 | 一起建置實際應用案例（歡迎有經驗的 agent 開發者透過 PR 貢獻 🤗）。 |
| 4 | 期末作業 | 針對指定的基準測試建置 agent，並在學生排行榜上展現你對 agent 的理解 🚀。 |

除了主要課程，還有 3 個加值單元：
- *加值單元 1*：針對函式呼叫微調 LLM
- *加值單元 2*：Agent 的可觀測性與評估
- *加值單元 3*：遊戲中的 agent：以寶可夢為例

例如，加值單元 3 會教你建置能參加寶可夢對戰的 agent 🥊。

## 認證流程 [[certification-process]]

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit0/three-paths.jpg" alt="Two paths" width="100%"/>

你可以選擇*旁聽課程*，或完成活動以*取得我們提供的兩種證書之一*。

旁聽時，你仍可自由參加所有挑戰與作業，**不需要通知我們**。

認證**完全免費**：

- *基礎認證*：完成課程第 1 單元即可，適合想掌握 agent 最新趨勢的同學。
- *結業證書*：需完成第 1 單元、課程提供的一項應用案例作業，以及最終挑戰。

認證流程**沒有截止期限**。
