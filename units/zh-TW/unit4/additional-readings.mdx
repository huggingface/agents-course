# 接下來該學哪些主題？

Agentic AI 是快速發展的領域。要建立具備智慧與自主性的系統，了解基礎協定十分重要。

以下兩項重要標準值得你認識：

- **Model Context Protocol（MCP）**
- **Agent-to-Agent Protocol（A2A）**

## 🔌 Model Context Protocol（MCP）

Anthropic 提出的 **Model Context Protocol（MCP）** 是一項開放標準，讓 AI 模型能安全、順暢地**連接外部工具、資料來源與應用程式**，使 agent 更有能力，也更具自主性。

你可以把 MCP 想成 **USB-C 連接埠這樣的通用轉接介面**，讓 AI 模型接上各種數位環境，**無須為每個環境個別開發整合功能**。

MCP 正迅速受到業界關注，OpenAI 與 Google 等大型公司也開始採用。

## 🤝 Agent-to-Agent（A2A）協定

Google 開發了 **Agent-to-Agent（A2A）協定**，與 Anthropic 的 Model Context Protocol（MCP）相輔相成。

MCP 讓 agent 連接外部工具，而 **A2A 讓 agent 彼此連接**，為協作式多 agent 系統鋪路，讓它們能共同解決複雜問題。
