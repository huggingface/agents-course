# 建立使用程式碼的 agent

code agent 是 `smolagents` 的預設 agent 類型。它們會產生 Python 工具呼叫來執行動作，以高效、準確且具表達力的方式描述行動。

這種精簡的做法能減少所需動作的數量、簡化複雜操作，並重複使用既有的程式碼函式。`smolagents` 提供建立 code agent 的輕量框架，核心實作約只有 1,000 行程式碼。

![程式碼動作與 JSON 動作](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/transformers/code_vs_json_actions.png)
圖片出自論文 [Executable Code Actions Elicit Better LLM Agents](https://huggingface.co/papers/2402.01030)。

> [!TIP]
> 想進一步了解 code agent 為何有效，請參閱 smolagents 文件中的<a href="https://huggingface.co/docs/smolagents/en/conceptual_guides/intro_agents#code-agents" target="_blank">這份指南</a>。

## 為什麼使用 code agent？

在多步驟 agent 流程中，LLM 會撰寫並執行動作，通常會呼叫外部工具。傳統做法以 JSON 格式將工具名稱與參數寫成字串，**系統必須解析這些內容，才能判斷要執行哪個工具**。

然而，研究顯示，**需要呼叫工具的 LLM 直接使用程式碼時，表現更好**。這也是 `smolagents` 的核心原則，如上方出自 [Executable Code Actions Elicit Better LLM Agents](https://huggingface.co/papers/2402.01030) 的圖所示。

以程式碼取代 JSON 撰寫動作，有幾項主要優點：

* **可組合性**：輕鬆組合並重複使用動作。
* **物件管理**：直接處理影像等複雜結構。
* **通用性**：表達任何可透過計算完成的任務。
* **適合 LLM**：LLM 的訓練資料中已包含高品質程式碼。

## code agent 如何運作？

![出自 https://huggingface.co/docs/smolagents/conceptual_guides/react](https://huggingface.co/datasets/huggingface/documentation-images/resolve/main/smolagents/codeagent_docs.png)

上圖說明 `CodeAgent.run()` 的運作方式，採用第一單元介紹的 ReAct 框架。`smolagents` 對 agent 的主要抽象是 `MultiStepAgent`，也是框架的核心組件。`CodeAgent` 是一種特殊的 `MultiStepAgent`，下方範例將進一步說明。

`CodeAgent` 透過一連串循環步驟執行動作，將既有變數與知識納入 agent 的上下文，並保留在執行紀錄中：

1. 系統 prompt 儲存在 `SystemPromptStep`，使用者查詢則記錄在 `TaskStep`。

2. 接著執行以下 while 迴圈：

    2.1 `agent.write_memory_to_messages()` 方法將 agent 的執行紀錄寫成 LLM 可讀取的[聊天訊息](https://huggingface.co/docs/transformers/main/en/chat_templating)清單。
    
    2.2 將訊息傳給 `Model`，產生補全文字（completion）。
    
    2.3 解析補全文字，擷取動作。在這個例子中，因為使用 `CodeAgent`，動作應該是一段程式碼。
    
    2.4 執行動作。
    
    2.5 將結果以 `ActionStep` 記錄到記憶中。

每一步結束時，如果 agent 在 `agent.step_callback` 中設有函式呼叫，就會執行它們。

### 使用自訂工具準備菜單

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/smolagents/alfred-menu.jpg" alt="Alfred Menu"/>

挑好歌單後，接著要替賓客安排菜單。Alfred 同樣可以使用 `smolagents` 完成。這裡使用 `@tool` 裝飾器定義自訂函式，將它作為工具。稍後我們會詳細介紹如何建立工具，目前先直接執行程式碼即可。

如下方範例所示，我們使用 `@tool` 裝飾器建立工具，再將它加入 `tools` 清單。

```python
from smolagents import CodeAgent, tool, InferenceClientModel

# Tool to suggest a menu based on the occasion
@tool
def suggest_menu(occasion: str) -> str:
    """
    Suggests a menu based on the occasion.
    Args:
        occasion (str): The type of occasion for the party. Allowed values are:
                        - "casual": Menu for casual party.
                        - "formal": Menu for formal party.
                        - "superhero": Menu for superhero party.
                        - "custom": Custom menu.
    """
    if occasion == "casual":
        return "Pizza, snacks, and drinks."
    elif occasion == "formal":
        return "3-course dinner with wine and dessert."
    elif occasion == "superhero":
        return "Buffet with high-energy and healthy food."
    else:
        return "Custom menu for the butler."

# Alfred, the butler, preparing the menu for the party
agent = CodeAgent(tools=[suggest_menu], model=InferenceClientModel())

# Preparing the menu for the party
agent.run("Prepare a formal menu for the party.")
```

agent 會執行幾個步驟，直到找到答案。在 docstring 中明確列出允許的值，能引導 agent 使用確實存在的 `occasion` 參數值，減少幻覺。

菜單準備好了！🥗

### 在 agent 內匯入 Python 模組

歌單與菜單都準備好了，但還有一項重要細節要確認：準備時間！

Alfred 需要計算，如果現在開始準備，所有工作何時能完成，以便判斷是否需要請其他超級英雄幫忙。

`smolagents` 專門支援會撰寫並執行 Python 程式碼片段的 agent，並以沙箱執行來提高安全性。

**程式碼執行有嚴格的安全措施**：預設會禁止匯入安全清單以外的模組。不過，可以透過 `additional_authorized_imports` 傳入模組名稱字串，允許額外匯入。
安全執行程式碼的更多細節，請參閱官方[指南](https://huggingface.co/docs/smolagents/tutorials/secure_code_execution)。

建立 agent 時，我們將使用 `additional_authorized_imports`，允許匯入 `datetime` 模組。

```python
from smolagents import CodeAgent, InferenceClientModel
import numpy as np
import time
import datetime

agent = CodeAgent(tools=[], model=InferenceClientModel(), additional_authorized_imports=['datetime'])

agent.run(
    """
    Alfred needs to prepare for the party. Here are the tasks:
    1. Prepare the drinks - 30 minutes
    2. Decorate the mansion - 60 minutes
    3. Set up the menu - 45 minutes
    4. Prepare the music and playlist - 45 minutes

    If we start right now, at what time will the party be ready?
    """
)
```


這些範例只是 code agent 能力的起點，但我們已經看見它在派對準備上的用途。
關於建立 code agent 的更多資訊，請參閱 [smolagents 文件](https://huggingface.co/docs/smolagents)。

總結來說，`smolagents` 專門支援撰寫並執行 Python 程式碼片段的 agent，並提供沙箱執行機制來提高安全性。它同時支援本機與透過 API 存取的語言模型，因此適用於各種開發環境。

你可能好奇，Alfred 如何使用 `smolagents` 建立這樣的 agent？將幾個工具整合起來，就能像下方這樣建立。目前不必擔心工具細節，本單元稍後會有專節深入介紹：

```python
from smolagents import CodeAgent, DuckDuckGoSearchTool, FinalAnswerTool, InferenceClientModel, Tool, tool, VisitWebpageTool

@tool
def suggest_menu(occasion: str) -> str:
    """
    Suggests a menu based on the occasion.
    Args:
        occasion: The type of occasion for the party.
    """
    if occasion == "casual":
        return "Pizza, snacks, and drinks."
    elif occasion == "formal":
        return "3-course dinner with wine and dessert."
    elif occasion == "superhero":
        return "Buffet with high-energy and healthy food."
    else:
        return "Custom menu for the butler."

@tool
def catering_service_tool(query: str) -> str:
    """
    This tool returns the highest-rated catering service in Gotham City.
    
    Args:
        query: A search term for finding catering services.
    """
    # Example list of catering services and their ratings
    services = {
        "Gotham Catering Co.": 4.9,
        "Wayne Manor Catering": 4.8,
        "Gotham City Events": 4.7,
    }
    
    # Find the highest rated catering service (simulating search query filtering)
    best_service = max(services, key=services.get)
    
    return best_service

class SuperheroPartyThemeTool(Tool):
    name = "superhero_party_theme_generator"
    description = """
    This tool suggests creative superhero-themed party ideas based on a category.
    It returns a unique party theme idea."""
    
    inputs = {
        "category": {
            "type": "string",
            "description": "The type of superhero party (e.g., 'classic heroes', 'villain masquerade', 'futuristic Gotham').",
        }
    }
    
    output_type = "string"

    def forward(self, category: str):
        themes = {
            "classic heroes": "Justice League Gala: Guests come dressed as their favorite DC heroes with themed cocktails like 'The Kryptonite Punch'.",
            "villain masquerade": "Gotham Rogues' Ball: A mysterious masquerade where guests dress as classic Batman villains.",
            "futuristic gotham": "Neo-Gotham Night: A cyberpunk-style party inspired by Batman Beyond, with neon decorations and futuristic gadgets."
        }
        
        return themes.get(category.lower(), "Themed party idea not found. Try 'classic heroes', 'villain masquerade', or 'futuristic Gotham'.")


# Alfred, the butler, preparing the menu for the party
agent = CodeAgent(
    tools=[
        DuckDuckGoSearchTool(), 
        VisitWebpageTool(),
        suggest_menu,
        catering_service_tool,
        SuperheroPartyThemeTool(),
	FinalAnswerTool()
    ], 
    model=InferenceClientModel(),
    max_steps=10,
    verbosity_level=2
)

agent.run("Give me the best playlist for a party at the Wayne's mansion. The party idea is a 'villain masquerade' theme")
```

如你所見，我們建立了一個具備多項工具的 `CodeAgent`，強化它的功能，讓它成為隨時能與社群分享的最強派對規劃幫手！🎉

### 使用 OpenTelemetry 與 Langfuse 檢視派對籌備 agent 📡

Alfred 持續調整派對籌備 agent，卻也漸漸厭倦替每次執行除錯。agent 的行為本來就難以預測，也不容易檢查。但他想打造最強的派對籌備 agent，並部署到正式環境，因此需要可靠的追蹤能力，方便日後監控與分析。

`smolagents` 再次派上用場！它採用 [OpenTelemetry](https://opentelemetry.io/) 標準，為 agent 的執行加入觀測功能，方便檢查與記錄。搭配 [Langfuse](https://langfuse.com/) 與 `SmolagentsInstrumentor`，Alfred 就能輕鬆追蹤並分析 agent 的行為。

設定方式很簡單！

首先，安裝必要的相依套件：

```bash
pip install opentelemetry-sdk opentelemetry-exporter-otlp openinference-instrumentation-smolagents langfuse
```

接著，Alfred 已經建立 Langfuse 帳號，並準備好 API 金鑰。如果你尚未完成，可以在[這裡](https://cloud.langfuse.com/)註冊 Langfuse Cloud，或探索[其他方案](https://huggingface.co/docs/smolagents/tutorials/inspect_runs)。

取得 API 金鑰後，依下列方式完成設定：

```python
import os

# Get keys for your project from the project settings page: https://cloud.langfuse.com
os.environ["LANGFUSE_PUBLIC_KEY"] = "pk-lf-..." 
os.environ["LANGFUSE_SECRET_KEY"] = "sk-lf-..." 
os.environ["LANGFUSE_HOST"] = "https://cloud.langfuse.com" # 🇪🇺 EU region
# os.environ["LANGFUSE_HOST"] = "https://us.cloud.langfuse.com" # 🇺🇸 US region
```

設定環境變數後，就能初始化 Langfuse client。`get_client()` 會使用環境變數中的憑證初始化 client。

```python
from langfuse import get_client
 
langfuse = get_client()
 
# Verify connection
if langfuse.auth_check():
    print("Langfuse client is authenticated and ready!")
else:
    print("Authentication failed. Please check your credentials and host.")
```

最後，Alfred 可以初始化 `SmolagentsInstrumentor`，開始追蹤 agent 的表現。

```python
from openinference.instrumentation.smolagents import SmolagentsInstrumentor

SmolagentsInstrumentor().instrument()
```

Alfred 連接成功了 🔌！`smolagents` 的執行過程正在記錄到 Langfuse，讓他能全面掌握 agent 的行為。有了這套設定，他可以回頭檢查先前的執行結果，進一步改善派對籌備 agent。
