## 內容

本單元將介紹以下 `smolagents` 主題：

### 1️⃣ [為什麼使用 smolagents](./why_use_smolagents)

`smolagents` 是可用於應用程式開發的眾多開源 agent 框架之一。其他選擇包括 `LlamaIndex` 和 `LangGraph`，本課程也會在其他模組介紹。`smolagents` 的幾項特色讓它很適合某些使用情境，但選擇框架時仍應全面評估。我們將探討它的優缺點，協助你根據專案需求做出判斷。

### 2️⃣ [CodeAgents](./code_agents)

`CodeAgents` 是 `smolagents` 的主要 agent 類型。它們透過產生 Python 程式碼來執行動作，而非輸出 JSON 或文字。本模組將介紹其用途、功能與運作方式，並透過實作範例展示它們的能力。

### 3️⃣ [ToolCallingAgents](./tool_calling_agents)

`ToolCallingAgents` 是 `smolagents` 支援的第二種 agent 類型。不同於產生 Python 程式碼的 `CodeAgents`，這類 agent 會輸出 JSON 或文字區塊，由系統解析後執行動作。本模組將介紹它們的功能、與 `CodeAgents` 的主要差異，並以範例說明用法。

### 4️⃣ [工具](./tools)

如第一單元所述，工具是 LLM 在 agent 系統中可以使用的函式，也是 agent 行為的基本組件。本模組將介紹工具的結構、建立方式，以及如何使用 `Tool` 類別或 `@tool` 裝飾器實作工具。你也會認識預設工具箱，學習如何與社群分享工具，以及載入社群提供的工具供 agent 使用。

### 5️⃣ [檢索 agent](./retrieval_agents)

檢索 agent 讓模型能存取知識庫，從多個來源搜尋、整合及檢索資訊。它們利用向量儲存空間提高檢索效率，實作**檢索增強生成（Retrieval-Augmented Generation，RAG）**模式。這類 agent 特別適合整合網頁搜尋與自訂知識庫，並透過記憶系統保留對話上下文。本模組將探討實作策略，包括在檢索失敗時採用的備援機制。

### 6️⃣ [多 agent 系統](./multi_agent_systems)

有效協調多個 agent，是建立強大多 agent 系統的關鍵。將不同能力的 agent 結合，例如網頁搜尋 agent 與程式碼執行 agent，就能打造更進階的解決方案。本模組著重於多 agent 系統的設計、實作與管理，以提升效率和可靠性。

### 7️⃣ [視覺與瀏覽器 agent](./vision_agents)

視覺 agent 整合**視覺語言模型（Vision-Language Models，VLM）**，擴充傳統 agent 的能力，讓它們能處理並解讀視覺資訊。本模組將介紹如何設計及整合由 VLM 驅動的 agent，實作影像推理、視覺資料分析與多模態互動等進階功能。我們也會利用視覺 agent 建立能瀏覽網頁並擷取資訊的瀏覽器 agent。
