# `LangGraph` 簡介

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/LangGraph/LangGraph.png" alt="Unit 2.3 Thumbnail"/>

歡迎來到學習旅程的下一站！您將學習**如何使用 [`LangGraph`](https://github.com/langchain-ai/langgraph) 框架建立應用程式**，組織並協調複雜的 LLM 工作流程。

`LangGraph` 提供**控制** agent 流程的工具，讓您建立**可部署至正式環境**的應用程式。
