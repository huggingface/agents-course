# LlamaIndex 簡介

歡迎來到本模組！您將學習如何使用 [LlamaIndex](https://www.llamaindex.ai/) 工具組，建立由 LLM 驅動的 agent。

LlamaIndex 是**一套完整工具組，可透過索引與工作流程，針對您的資料建立由 LLM 驅動的 agent**。本課程將聚焦於在 LlamaIndex 中建立 agent 的三個主要部分：**元件**、**agent 與工具**以及**工作流程**。

![LlamaIndex](https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/llama-index/thumbnail.png)

讓我們看看 LlamaIndex 的這些核心部分，以及它們如何協助 agent：

- **元件**：LlamaIndex 的基本構成要素，包括 prompt、模型與資料庫等。元件通常用來連接 LlamaIndex 與其他工具和函式庫。
- **工具**：提供特定能力的元件，例如搜尋、計算或存取外部服務。它們是讓 agent 執行任務的基礎。
- **agent**：能自主使用工具並做出決策的元件，透過協調工具的使用來完成複雜目標。
- **工作流程**：將邏輯串連起來、逐步執行的流程。工作流程或 agentic 工作流程，能在不直接使用 agent 的情況下組織 agentic 行為。

## LlamaIndex 有什麼特色？

雖然 LlamaIndex 的部分功能與 smolagents 等框架相似，但它具備幾項主要優勢：

- **清楚的工作流程系統**：透過事件驅動、以非同步為優先的語法，將 agent 的決策拆成明確步驟，方便您組合與組織邏輯。
- **透過 LlamaParse 進階解析文件**：LlamaParse 專為 LlamaIndex 設計，因此整合十分順暢，不過這是付費功能。
- **豐富的現成元件**：LlamaIndex 發展已有一段時間，能與許多框架搭配使用，並提供大量經過測試的可靠元件，例如 LLM、檢索器與索引。
- **LlamaHub**：收錄數百種元件、agent 與工具的資源目錄，這些資源都能在 LlamaIndex 中使用。
