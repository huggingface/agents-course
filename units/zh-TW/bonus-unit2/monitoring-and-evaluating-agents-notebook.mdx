### Trace 結構

多數可觀測性工具會記錄包含多個 **span** 的 **trace**，每個 span 代表 agent 邏輯中的一個步驟。這裡的 trace 包含 agent 的完整執行過程，以及下列操作的子 span：
- 工具呼叫（DuckDuckGoSearchTool）
- LLM 呼叫（InferenceClientModel）

## 線上評估

### 正式環境中常見的追蹤指標

1. **成本** — smolagents 的監測功能會記錄 token 用量。只要指定每個 token 的價格，就能換算出大約成本。
2. **延遲** — 觀察每個步驟或整次執行所需的時間。
3. **使用者回饋** — 使用者可以直接按讚或倒讚，幫助你調整或修正 agent。
4. **LLM-as-a-Judge** — 使用另一個 LLM，近乎即時地評估 agent 的輸出，例如檢查有害內容或正確性。

以下會示範這些指標。

#### 3. 額外屬性

你也可以傳入額外的 span 屬性，例如 `user_id`、`tags`、`session_id` 與自訂中繼資料。在 trace 中加入這些細節，有助於分析、除錯，以及監控應用程式在不同使用者或工作階段中的行為。

```python
from smolagents import (CodeAgent, DuckDuckGoSearchTool, InferenceClientModel)

search_tool = DuckDuckGoSearchTool()
agent = CodeAgent(
    tools=[search_tool],
    model=InferenceClientModel()
)

with langfuse.start_as_current_span(
    name="Smolagent-Trace",
    ) as span:
    
    # Run your application here
    response = agent.run("What is the capital of Germany?")
 
    # Pass additional attributes to the span
    span.update_trace(
        input="What is the capital of Germany?",
        output=response,
        user_id="smolagent-user-123",
        session_id="smolagent-session-123456789",
        tags=["city-question", "testing-agents"],
        metadata={"email": "user@langfuse.com"},
        )
 
# Flush events in short-lived applications
langfuse.flush()
```

#### 4. 使用者回饋

如果 agent 嵌入在使用者介面中，就能記錄使用者的直接回饋，例如聊天介面中的按讚或倒讚。下例使用 [Gradio](https://gradio.app/)，建立具有簡單回饋機制的聊天介面。

以下程式碼會在使用者傳送聊天訊息時，將 trace 記錄到 Langfuse。如果使用者對最後一則回答按讚或倒讚，我們就將分數附加到該 trace。

```python
import gradio as gr
from smolagents import (CodeAgent, InferenceClientModel)
from langfuse import get_client

langfuse = get_client()

model = InferenceClientModel()
agent = CodeAgent(tools=[], model=model, add_base_tools=True)

trace_id = None

def respond(prompt, history):
    with langfuse.start_as_current_span(
        name="Smolagent-Trace"):
        
        # Run your application here
        output = agent.run(prompt)

        global trace_id
        trace_id = langfuse.get_current_trace_id()

    history.append({"role": "assistant", "content": str(output)})
    return history

def handle_like(data: gr.LikeData):
    # For demonstration, we map user feedback to a 1 (like) or 0 (dislike)
    if data.liked:
        langfuse.create_score(
            value=1,
            name="user-feedback",
            trace_id=trace_id
        )
    else:
        langfuse.create_score(
            value=0,
            name="user-feedback",
            trace_id=trace_id
        )

with gr.Blocks() as demo:
    chatbot = gr.Chatbot(label="Chat", type="messages")
    prompt_box = gr.Textbox(placeholder="Type your message...", label="Your message")

    # When the user presses 'Enter' on the prompt, we run 'respond'
    prompt_box.submit(
        fn=respond,
        inputs=[prompt_box, chatbot],
        outputs=chatbot
    )

    # When the user clicks a 'like' button on a message, we run 'handle_like'
    chatbot.like(handle_like, None, None)

demo.launch()
```

#### 5. LLM-as-a-Judge

LLM-as-a-Judge 是另一種自動評估 agent 輸出的方法。你可以另外呼叫 LLM，依照正確性、有害程度、風格，或任何你在意的標準來評估輸出。

**工作流程**：
1. 定義**評估範本**，例如「檢查這段文字是否有害」。
2. 每當 agent 產生輸出，就將輸出連同範本傳給擔任「評審」的 LLM。
3. 評審 LLM 回傳評分或標籤，再將結果記錄到可觀測性工具。

以下是 Langfuse 的範例：

![LLM-as-a-Judge 評估範本](https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/bonus-unit2/evaluator-template.png)
![LLM-as-a-Judge 評估器](https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/bonus-unit2/evaluator.png)

```python
# Example: Checking if the agent’s output is toxic or not.
from smolagents import (CodeAgent, DuckDuckGoSearchTool, InferenceClientModel)

agent = CodeAgent(tools=[search_tool], model=InferenceClientModel())
```

## 離線評估

線上評估能取得即時回饋，但你也需要**離線評估**，在開發前或開發期間進行系統化檢查。這能在變更上線前，幫助你維持品質與可靠性。

### 資料集評估

離線評估通常包含以下步驟：
1. 準備基準資料集，其中包含成對的 prompt 與預期輸出
2. 讓 agent 處理資料集
3. 將輸出與預期結果比較，或使用額外的評分機制

以下使用包含數學題目與解答的 [GSM8K 資料集](https://huggingface.co/datasets/openai/gsm8k)，示範這個做法。

```python
import pandas as pd
from datasets import load_dataset

# Fetch GSM8K from Hugging Face
dataset = load_dataset("openai/gsm8k", 'main', split='train')
df = pd.DataFrame(dataset)
print("First few rows of GSM8K dataset:")
print(df.head())
```

接著，在 Langfuse 中建立資料集實體來追蹤執行紀錄，再將資料集中的每個項目加入系統。如果你不使用 Langfuse，也可以直接存入自己的資料庫或本機檔案，供後續分析。

#### 讓 agent 處理資料集

我們定義一個輔助函式 `run_smolagent()`，它會：
1. 啟動 Langfuse span
2. 讓 agent 處理 prompt
3. 在 Langfuse 中記錄 trace ID

接著，逐一處理資料集項目，執行 agent，並將 trace 與對應項目連結。也可以視需要附加簡單的評估分數。

```python
from opentelemetry.trace import format_trace_id
from smolagents import (CodeAgent, InferenceClientModel, LiteLLMModel)
from langfuse import get_client
 
langfuse = get_client()


# Example: using InferenceClientModel or LiteLLMModel to access openai, anthropic, gemini, etc. models:
model = InferenceClientModel()

agent = CodeAgent(
    tools=[],
    model=model,
    add_base_tools=True
)

dataset_name = "gsm8k_dataset_huggingface"
current_run_name = "smolagent-notebook-run-01" # Identifies this specific evaluation run
 
# Assume 'run_smolagent' is your instrumented application function
def run_smolagent(question):
    with langfuse.start_as_current_generation(name="qna-llm-call") as generation:
        # Simulate LLM call
        result = agent.run(question)
 
        # Update the trace with the input and output
        generation.update_trace(
            input= question,
            output=result,
        )
 
        return result
 
dataset = langfuse.get_dataset(name=dataset_name) # Fetch your pre-populated dataset
 
for item in dataset.items:
 
    # Use the item.run() context manager
    with item.run(
        run_name=current_run_name,
        run_metadata={"model_provider": "Hugging Face", "temperature_setting": 0.7},
        run_description="Evaluation run for GSM8K dataset"
    ) as root_span: # root_span is the root span of the new trace for this item and run.
        # All subsequent langfuse operations within this block are part of this trace.
 
        # Call your application logic
        generated_answer = run_smolagent(question=item.input["text"])
 
        print(item.input)
```

你可以變更以下設定，重複執行這個流程：
- 模型（OpenAI GPT、本機 LLM 等）
- 工具（使用搜尋或不使用搜尋）
- prompt（不同的系統訊息）
