# AI agent 的可觀測性與評估

![附加單元 2 縮圖](https://langfuse.com/images/cookbook/huggingface-agent-course/agent-observability-and-evaluation.png)

歡迎來到**附加單元 2**！本章將介紹觀察、評估 agent 的進階策略，幫助你持續改善 agent 的表現。

---

## 📚 什麼時候適合學習這個附加單元？

如果你有以下需求，這個單元很適合你：
- **開發與部署 AI agent：** 希望確保 agent 在正式環境中穩定可靠。
- **深入了解運作細節：** 想要診斷問題、改善效能，或了解 agent 的內部運作。
- **降低維運負擔：** 透過監控 agent 的成本、延遲與執行細節，有效率地管理資源。
- **持續改進：** 希望在 AI 應用程式中整合即時使用者回饋與自動化評估。

也就是說，只要你想讓使用者實際使用 agent，這個單元就適合你！

---

## 🤓 你將學到什麼

在本單元，你將學習：
- **為 agent 加入監測：** 透過 OpenTelemetry，將可觀測性工具與 *smolagents* 框架整合。
- **監控指標：** 追蹤 token 用量（成本）、延遲、錯誤追蹤等效能指標。
- **即時評估：** 了解線上評估技巧，包括收集使用者回饋，以及讓 LLM 擔任評審。
- **離線分析：** 使用 GSM8K 等基準資料集，測試與比較 agent 的表現。
