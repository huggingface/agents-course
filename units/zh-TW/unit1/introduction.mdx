# agent 簡介

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit1/thumbnail.jpg" alt="Thumbnail"/>

歡迎來到第一單元！你將在這裡**打好 AI agent 的基礎**，包括：

- **認識 agent**  
  - 什麼是 agent？它如何運作？  
  - agent 如何運用推理與規劃做決策？

- **LLM（大型語言模型）在 agent 中的角色**  
  - LLM 如何成為 agent 的「大腦」。  
  - LLM 如何透過訊息系統組織對話。

- **工具與行動**  
  - agent 如何使用外部工具與環境互動。  
  - 如何為 agent 建立並整合工具。

- **agent 的工作流程：** 
  - *思考* → *行動* → *觀察*。

學完這些主題後，**你將使用 `smolagents` 建立第一個 agent**！

這個名為 Alfred 的 agent 會處理一項簡單任務，示範如何實際運用這些概念。

你還會學到如何**將 agent 發布到 Hugging Face Spaces**，與朋友和同事分享。

最後，你將在單元結束時參加測驗。通過後，就能**取得第一張課程證書**：🎓 agent 基礎證書。

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit1/certificate-example.jpg" alt="Certificate Example"/>

本單元是你的**重要起點**，幫助你在進入進階主題之前，先打好理解 agent 的基礎。
