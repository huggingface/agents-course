# 思考：內部推理與 ReAct 方法

> [!TIP]
> 本節將深入探討 AI agent 的內部運作，也就是推理與規劃的能力。我們將了解 agent 如何透過內部對話分析資訊，將複雜問題拆解成可處理的步驟，並決定下一步行動。
>
> 此外，我們會介紹 ReAct 方法，這種 prompt 技巧會鼓勵模型在行動前「逐步思考」。

思考代表 **agent 為了解決任務而進行的內部推理與規劃過程**。

這個過程運用 agent 的大型語言模型（LLM）能力，**分析 prompt 中提供的資訊**，就像它處理問題時的內心獨白。

agent 的思考有助於評估目前的觀察結果，決定接下來該採取哪些行動。透過這個過程，agent 能**將複雜問題拆解成較小、較容易處理的步驟**，反思過往經驗，並依據新資訊持續調整計畫。

## 🧠 常見思考類型範例

| 思考類型 | 範例 |
|--------------------|-------------------------------------------------------------------------|
| 規劃 | 「我需要把這項任務分成三個步驟：1）收集資料，2）分析趨勢，3）產生報告。」 |
| 分析 | 「根據錯誤訊息，問題似乎出在資料庫連線參數。」 |
| 決策 | 「考量使用者的預算限制，我應該推薦中階方案。」 |
| 解決問題 | 「要讓這段程式碼更有效率，我應該先分析效能，找出瓶頸。」 |
| 記憶整合 | 「使用者先前提過偏好 Python，所以我會提供 Python 範例。」 |
| 自我反思 | 「上次的方法效果不好，我應該試試不同策略。」 |
| 目標設定 | 「要完成這項任務，我需要先訂出驗收標準。」 |
| 優先順序 | 「新增功能之前，應該先修補安全漏洞。」 |

> **注意：**對於經過函式呼叫微調的 LLM，思考過程是選用的。「行動」一節會進一步說明。

## 🔗 思維鏈（Chain-of-Thought，CoT）

**思維鏈（CoT）**是一種 prompt 技巧，引導模型**先逐步思考問題，再產生最終答案**。

通常會以下列句子開頭：  
> *「讓我們逐步思考。」*

這種方法有助於模型**在內部推理**，尤其適合邏輯或數學任務，而且**不會與外部工具互動**。

### ✅ 範例（CoT）
```
Question: What is 15% of 200?
Thought: Let's think step by step. 10% of 200 is 20, and 5% of 200 is 10, so 15% is 30.
Answer: 30
```

## ⚙️ ReAct：推理 + 行動

一個重要方法是 **ReAct**，結合「推理」（Reasoning／Think）與「行動」（Acting／Act）。

ReAct 是一種 prompt 技巧，鼓勵模型逐步思考，並在推理步驟之間穿插行動，例如使用工具。

agent 會交替進行下列步驟，藉此解決複雜的多步驟任務：
- 思考：內部推理
- 行動：使用工具
- 觀察：接收工具輸出

### 🔄 範例（ReAct）
```
Thought: I need to find the latest weather in Paris.
Action: Search["weather in Paris"]
Observation: It's 18°C and cloudy.
Thought: Now that I know the weather...
Action: Finish["It's 18°C and cloudy in Paris."]
```

## 🔁 比較 ReAct 與 CoT

| 特性 | 思維鏈（CoT） | ReAct |
|----------------------|-----------------------------|-------------------------------------|
| 逐步推理 | ✅ 是 | ✅ 是 |
| 外部工具 | ❌ 否 | ✅ 是（行動 + 觀察） |
| 適合的任務 | 邏輯、數學、內部任務 | 資訊查找、動態多步驟任務 |

> [!TIP]
> **Deepseek R1** 或 **OpenAI 的 o1** 等近期模型經過微調，會*先思考再回答*。它們使用 `<think>` 與 `</think>` 等結構化 token，明確區分推理階段與最終答案。
>
> ReAct 和 CoT 是 prompt 策略；這裡則是**訓練層級的技術**，模型透過範例學習如何思考。
