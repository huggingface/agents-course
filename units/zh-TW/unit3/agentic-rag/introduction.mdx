# Agentic RAG 應用案例介紹

![Agentic RAG 橫幅](https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit3/agentic-rag/thumbnail.jpg)

本單元將運用 Agentic RAG，為負責主持晚宴的親切 agent Alfred 建立工具，幫助他回答關於晚宴賓客的問題。

> [!TIP]
> 這是 Agentic RAG 的實際應用案例，你也可以用在自己的專案或工作中。如果想從這個專案學到更多，不妨試著套用到自己的應用情境，再到 Discord 分享成果！

你可以選用課程中介紹的任何框架。我們在各個分頁中提供了對應的程式碼範例。

## 一場令人難忘的晚宴

現在就來動手實作，先設定這個案例的背景吧！

**你決定舉辦本世紀最奢華、最盛大的派對。** 現場將有豐盛的宴席、迷人的舞者、知名 DJ、精緻飲品、令人驚豔的煙火秀，以及更多精彩節目。

你親切的好鄰居 agent Alfred，正準備照料這場派對的各種需求，**而且 Alfred 打算親自管理所有事務**。為此，他需要取得派對的所有資訊，包括菜單、賓客、活動時程、天氣預報等等！

此外，他還得確保派對圓滿成功，因此**必須能在派對期間回答任何與派對有關的問題**，同時處理可能發生的突發狀況。

他無法獨力完成這些事，所以我們要確保 Alfred 能取得所需的所有資訊與工具。

首先，來列出這場晚宴必須滿足的需求。

## 晚宴需求

在**文藝復興時期**，一位受過良好教育的人應具備三項主要素養。
也就是精通**運動、文化與科學知識**。因此，我們得確保自己能以豐富的知識讓賓客留下深刻印象，為他們帶來真正難忘的晚宴。
不過，為了避免衝突，**晚宴中應避開政治與宗教等話題。** 這應該是一場歡樂的派對，不該因信仰與理念的差異而起爭執。

依照社交禮儀，**好主人應了解賓客的背景**，包括他們的興趣與事業。好主人也會聊聊賓客的趣聞，讓大家彼此分享故事。

最後，我們也得具備**一些天氣常識**，並能持續查詢即時天氣，才能選在最合適的時機施放煙火，為晚宴畫下精彩的句點！🎆

可見 Alfred 需要大量資訊，才能主持好這場晚宴。
幸好，我們可以透過**檢索增強生成（Retrieval Augmented Generation，RAG）訓練**，協助 Alfred 做好準備！

現在就開始建立 Alfred 主持晚宴所需的工具吧！
