# 結語

本單元中，我們學會建立 Agentic RAG 系統，協助親切的好鄰居 agent Alfred 準備並管理一場奢華晚宴。

將 RAG 與 agent 的能力結合，展現了 AI 助理在具備下列能力後，可以發揮多大的作用：
- 存取結構化知識（賓客資訊）
- 擷取即時資訊（網頁搜尋）
- 使用特定領域的工具（天氣資訊、Hub 統計資料）
- 記住過去的互動

有了這些能力，Alfred 已準備好成為出色的主人：回答關於賓客的問題、提供最新資訊，並確保晚宴順利進行，甚至能掌握施放煙火的最佳時機！

> [!TIP]
> 現在你已建立完整的 agent，接下來不妨探索：
>
> - 針對自己的應用情境，建立更專門的工具
> - 運用嵌入向量，實作更進階的 RAG 系統
> - 建立讓 agent 彼此協作的多 agent 系統
> - 將 agent 部署成可供他人互動的服務
