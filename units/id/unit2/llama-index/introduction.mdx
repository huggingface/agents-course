# Pengantar LlamaIndex

Selamat datang di modul ini. Di sini, kamu akan belajar cara membuat agents berbasis LLM dengan toolkit [LlamaIndex](https://www.llamaindex.ai/).

LlamaIndex adalah **toolkit lengkap untuk membuat agents berbasis LLM di atas datamu dengan indexes dan workflows**. Dalam kursus ini, kita akan fokus pada tiga bagian utama yang membantu pembuatan agents di LlamaIndex: **Components**, **Agents and Tools**, dan **Workflows**.

![LlamaIndex](https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/llama-index/thumbnail.png)

Mari kita lihat bagian-bagian utama LlamaIndex dan bagaimana semuanya membantu agents:

- **Components**: building blocks dasar yang kamu pakai di LlamaIndex. Contohnya prompts, models, dan databases. Components sering membantu menghubungkan LlamaIndex dengan tools dan libraries lain.
- **Tools**: components yang menyediakan kemampuan spesifik seperti mencari, menghitung, atau mengakses layanan eksternal. Tools adalah building blocks yang memungkinkan agents menjalankan tugas.
- **Agents**: components otonom yang bisa memakai tools dan mengambil keputusan. Agents mengoordinasikan penggunaan tool untuk mencapai tujuan yang kompleks.
- **Workflows**: proses bertahap yang menyatukan logic. Workflows atau agentic workflows adalah cara menyusun agentic behaviour tanpa harus memakai agents secara eksplisit.


## Apa yang Membuat LlamaIndex Spesial?

Walaupun LlamaIndex melakukan beberapa hal yang mirip dengan framework lain seperti smolagents, ada beberapa manfaat yang membuatnya menonjol:

- **Clear Workflow System**: Workflows membantu memecah cara agents mengambil keputusan langkah demi langkah dengan sintaks event-driven dan async-first. Ini membantu kamu menyusun dan mengatur logic dengan jelas.
- **Advanced Document Parsing dengan LlamaParse**: LlamaParse dibuat khusus untuk LlamaIndex, jadi integrasinya mulus, meski fitur ini berbayar.
- **Banyak Components Siap Pakai**: LlamaIndex sudah ada cukup lama, sehingga bisa bekerja dengan banyak framework lain. Artinya, LlamaIndex punya banyak components yang sudah teruji dan andal, seperti LLMs, retrievers, indexes, dan lainnya.
- **LlamaHub**: registry berisi ratusan components, agents, dan tools yang bisa kamu pakai di dalam LlamaIndex.

Semua konsep ini dibutuhkan dalam skenario yang berbeda untuk membuat agents yang berguna.
