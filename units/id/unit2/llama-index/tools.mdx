# Menggunakan Tools di LlamaIndex

**Mendefinisikan kumpulan Tools yang jelas sangat berpengaruh pada performa.** Seperti yang kita bahas di [unit 1](../../unit1/tools), tool interfaces yang jelas lebih mudah digunakan oleh LLM.
Mirip seperti software API interface untuk engineer manusia, LLM bisa mendapatkan hasil lebih baik dari tool jika cara kerjanya mudah dipahami.

Ada **empat jenis tools utama di LlamaIndex**:

![Tools](https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/llama-index/tools.png)

1. `FunctionTool`: mengubah fungsi Python apa pun menjadi tool yang bisa dipakai agent. Tool ini otomatis memahami cara kerja fungsi.
2. `QueryEngineTool`: tool yang memungkinkan agents memakai query engines. Karena agents dibangun di atas query engines, mereka juga bisa memakai agents lain sebagai tools.
3. `Toolspecs`: kumpulan tools yang dibuat komunitas, sering kali berisi tools untuk layanan tertentu seperti Gmail.
4. `Utility Tools`: tools khusus yang membantu menangani data dalam jumlah besar dari tools lain.

Kita akan membahas masing-masing secara lebih detail di bawah.

## Membuat FunctionTool

> [!TIP]
> Kamu bisa mengikuti kode di <a href="https://huggingface.co/agents-course/notebooks/blob/main/unit2/llama-index/tools.ipynb" target="_blank">notebook ini</a> yang bisa dijalankan dengan Google Colab.

FunctionTool menyediakan cara sederhana untuk membungkus fungsi Python apa pun dan membuatnya tersedia bagi agent.
Kamu bisa meneruskan fungsi sinkron atau asinkron ke tool, bersama parameter opsional `name` dan `description`.
Nama dan deskripsi sangat penting karena membantu agent memahami kapan dan bagaimana memakai tool secara efektif.
Mari lihat cara membuat FunctionTool di bawah, lalu memanggilnya.

```python
from llama_index.core.tools import FunctionTool

def get_weather(location: str) -> str:
    """Useful for getting the weather for a given location."""
    print(f"Getting weather for {location}")
    return f"The weather in {location} is sunny"

tool = FunctionTool.from_defaults(
    get_weather,
    name="my_weather_tool",
    description="Useful for getting the weather for a given location.",
)
tool.call("New York")
```

> [!TIP]
> Saat memakai agent atau LLM dengan function calling, tool yang dipilih (dan argumen yang ditulis untuk tool tersebut) sangat bergantung pada nama tool serta deskripsi tujuan dan argumen tool. Pelajari function calling lebih lanjut di <a href="https://docs.llamaindex.ai/en/stable/examples/workflow/function_calling_agent/">Function Calling Guide</a>.

## Membuat QueryEngineTool

`QueryEngine` yang kita definisikan di unit sebelumnya bisa dengan mudah diubah menjadi tool memakai class `QueryEngineTool`.
Mari lihat cara membuat `QueryEngineTool` dari `QueryEngine` pada contoh di bawah.

```python
from llama_index.core import VectorStoreIndex
from llama_index.core.tools import QueryEngineTool
from llama_index.llms.huggingface_api import HuggingFaceInferenceAPI
from llama_index.embeddings.huggingface import HuggingFaceEmbedding
from llama_index.vector_stores.chroma import ChromaVectorStore

embed_model = HuggingFaceEmbedding("BAAI/bge-small-en-v1.5")

db = chromadb.PersistentClient(path="./alfred_chroma_db")
chroma_collection = db.get_or_create_collection("alfred")
vector_store = ChromaVectorStore(chroma_collection=chroma_collection)

index = VectorStoreIndex.from_vector_store(vector_store, embed_model=embed_model)

llm = HuggingFaceInferenceAPI(model_name="Qwen/Qwen2.5-Coder-32B-Instruct")
query_engine = index.as_query_engine(llm=llm)
tool = QueryEngineTool.from_defaults(query_engine, name="some useful name", description="some useful description")
```

## Membuat Toolspecs

Bayangkan `ToolSpecs` sebagai kumpulan tools yang bekerja bersama dengan rapi, seperti toolkit profesional yang tersusun baik.
Seperti toolkit mekanik yang berisi tools saling melengkapi untuk memperbaiki kendaraan, `ToolSpec` menggabungkan tools terkait untuk tujuan tertentu.
Misalnya, `ToolSpec` untuk agent akuntansi dapat mengintegrasikan kemampuan spreadsheet, fungsi email, dan tools kalkulasi untuk menangani tugas keuangan dengan presisi dan efisiensi.

<details>
<summary>Instal Google Toolspec</summary>
Seperti diperkenalkan pada <a href="./llama-hub">bagian tentang LlamaHub</a>, kita bisa menginstal Google toolspec dengan perintah berikut:

```python
pip install llama-index-tools-google
```
</details>

Sekarang kita bisa memuat toolspec dan mengubahnya menjadi daftar tools.

```python
from llama_index.tools.google import GmailToolSpec

tool_spec = GmailToolSpec()
tool_spec_list = tool_spec.to_tool_list()
```

Untuk melihat tools dengan lebih detail, kita bisa memeriksa `metadata` dari setiap tool.

```python
[(tool.metadata.name, tool.metadata.description) for tool in tool_spec_list]
```

### Model Context Protocol (MCP) di LlamaIndex

LlamaIndex juga memungkinkan penggunaan MCP tools melalui [ToolSpec di LlamaHub](https://llamahub.ai/l/tools/llama-index-tools-mcp?from=).
Kamu cukup menjalankan MCP server dan mulai memakainya melalui implementasi berikut.

Kalau ingin mempelajari MCP lebih dalam, kamu bisa membuka [MCP Course gratis](https://huggingface.co/learn/mcp-course/) kami.

<details>
<summary>Instal MCP Toolspec</summary>
Seperti diperkenalkan pada <a href="./llama-hub">bagian tentang LlamaHub</a>, kita bisa menginstal MCP toolspec dengan perintah berikut:

```python
pip install llama-index-tools-mcp
```
</details>

```python
from llama_index.tools.mcp import BasicMCPClient, McpToolSpec

# Kita anggap ada mcp server yang berjalan di 127.0.0.1:8000, atau kamu bisa memakai mcp client untuk terhubung ke mcp server milikmu sendiri.
mcp_client = BasicMCPClient("http://127.0.0.1:8000/sse")
mcp_tool = McpToolSpec(client=mcp_client)

# dapatkan agent
agent = await get_agent(mcp_tool)

# buat agent context
agent_context = Context(agent)
```

## Utility Tools

Sering kali, melakukan query langsung ke API **dapat mengembalikan data terlalu banyak**. Sebagian datanya mungkin tidak relevan, melampaui context window LLM, atau menaikkan jumlah token yang kamu pakai tanpa perlu.
Mari bahas dua utility tools utama di bawah.

1. `OnDemandToolLoader`: tool ini mengubah data loader LlamaIndex yang sudah ada (class BaseReader) menjadi tool yang bisa dipakai agent. Tool ini bisa dipanggil dengan semua parameter yang diperlukan untuk memicu `load_data` dari data loader, beserta string query bahasa natural. Saat dieksekusi, kita pertama-tama memuat data dari data loader, meng-index-nya (misalnya dengan vector store), lalu melakukan query secara 'on-demand'. Ketiga langkah ini terjadi dalam satu tool call.
2. `LoadAndSearchToolSpec`: LoadAndSearchToolSpec menerima Tool yang sudah ada sebagai input. Sebagai tool spec, ia mengimplementasikan `to_tool_list`, dan saat fungsi itu dipanggil, dua tools dikembalikan: loading tool lalu search tool. Eksekusi load Tool akan memanggil Tool di bawahnya, lalu meng-index output-nya (secara default dengan vector index). Eksekusi search Tool akan menerima string query sebagai input dan memanggil index di bawahnya.

> Kamu bisa menemukan toolspecs dan utility tools di <a href="https://llamahub.ai/">LlamaHub</a>
