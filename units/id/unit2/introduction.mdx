## Kapan Menggunakan Agentic Framework

Agentic framework **tidak selalu dibutuhkan saat membangun aplikasi berbasis LLM**. Framework semacam ini memberi fleksibilitas dalam workflow untuk menyelesaikan tugas tertentu secara efisien, tapi tidak selalu perlu.

Kadang, **workflow yang sudah ditentukan sebelumnya sudah cukup** untuk memenuhi permintaan user, sehingga agentic framework tidak benar-benar dibutuhkan. Kalau pendekatan untuk membangun agent masih sederhana, misalnya berupa rangkaian prompt, plain code bisa saja cukup. Keuntungannya, developer punya **kontrol dan pemahaman penuh atas sistemnya tanpa lapisan abstraksi**.

Namun, saat workflow makin rumit, misalnya ketika kita membiarkan LLM memanggil function atau menggunakan beberapa agent, abstraksi seperti ini mulai terasa membantu.

Dengan gagasan tersebut, kita sudah bisa mengenali beberapa fitur yang dibutuhkan:

* *LLM engine* yang menjalankan sistem.
* *List of tools* yang bisa diakses agent.
* *Parser* untuk mengekstrak tool calls dari output LLM.
* *System prompt* yang sinkron dengan parser.
* *Memory system*.
* *Error logging dan retry mechanisms* untuk mengendalikan kesalahan LLM.

Kita akan melihat bagaimana topik-topik ini ditangani di berbagai framework, termasuk `smolagents`, `LlamaIndex`, dan `LangGraph`.
