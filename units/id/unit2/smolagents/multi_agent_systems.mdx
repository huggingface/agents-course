# Sistem Multi-Agent

Multi-agent systems memungkinkan **specialized agents berkolaborasi pada tugas kompleks**, sehingga modularity, scalability, dan robustness meningkat. Alih-alih bergantung pada satu agent, tugas dibagi ke beberapa agents dengan kemampuan berbeda.

Di **smolagents**, berbagai agents bisa digabungkan untuk menghasilkan kode Python, memanggil external tools, melakukan web search, dan banyak lagi. Dengan mengorkestrasi agents ini, kita bisa membuat workflow yang kuat.

Setup umum dapat mencakup:
- **Manager Agent** untuk delegasi tugas
- **Code Interpreter Agent** untuk code execution
- **Web Search Agent** untuk information retrieval

Diagram di bawah menggambarkan arsitektur multi-agent sederhana. Di sini, **Manager Agent** mengoordinasikan **Code Interpreter Tool** dan **Web Search Agent**, yang kemudian menggunakan tools seperti `DuckDuckGoSearchTool` dan `VisitWebpageTool` untuk mengumpulkan informasi relevan.

## Multi-Agent Systems dalam Praktik

Multi-agent system terdiri dari beberapa specialized agents yang bekerja bersama di bawah koordinasi **Orchestrator Agent**. Pendekatan ini memungkinkan workflow kompleks dengan membagi tugas ke agents yang memiliki peran berbeda.

Misalnya, **Multi-Agent RAG system** bisa mengintegrasikan:
- **Web Agent** untuk menjelajahi internet.
- **Retriever Agent** untuk mengambil informasi dari knowledge bases.
- **Image Generation Agent** untuk membuat visual.

Semua agents ini berjalan di bawah orchestrator yang mengelola delegasi tugas dan interaksi.

### Pertama, kita membuat tool untuk mendapatkan waktu transfer cargo plane.

```python
import math
from typing import Optional, Tuple

from smolagents import tool


@tool
def calculate_cargo_travel_time(
    origin_coords: Tuple[float, float],
    destination_coords: Tuple[float, float],
    cruising_speed_kmh: Optional[float] = 750.0,  # Kecepatan rata-rata cargo plane
) -> float:
    """
    Calculate the travel time for a cargo plane between two points on Earth using great-circle distance.

    Args:
        origin_coords: Tuple of (latitude, longitude) for the starting point
        destination_coords: Tuple of (latitude, longitude) for the destination
        cruising_speed_kmh: Optional cruising speed in km/h (defaults to 750 km/h for typical cargo planes)

    Returns:
        float: The estimated travel time in hours

    Example:
        >>> # Chicago (41.8781° N, 87.6298° W) to Sydney (33.8688° S, 151.2093° E)
        >>> result = calculate_cargo_travel_time((41.8781, -87.6298), (-33.8688, 151.2093))
    """

    def to_radians(degrees: float) -> float:
        return degrees * (math.pi / 180)

    # Ekstrak koordinat
    lat1, lon1 = map(to_radians, origin_coords)
    lat2, lon2 = map(to_radians, destination_coords)

    # Radius Bumi dalam kilometer
    EARTH_RADIUS_KM = 6371.0

    # Hitung great-circle distance menggunakan formula haversine
    dlon = lon2 - lon1
    dlat = lat2 - lat1

    a = (
        math.sin(dlat / 2) ** 2
        + math.cos(lat1) * math.cos(lat2) * math.sin(dlon / 2) ** 2
    )
    c = 2 * math.asin(math.sqrt(a))
    distance = EARTH_RADIUS_KM * c

    # Tambahkan 10% untuk memperhitungkan rute tidak langsung dan air traffic control
    actual_distance = distance * 1.1

    # Hitung waktu penerbangan
    # Tambahkan 1 jam untuk prosedur lepas landas dan mendarat
    flight_time = (actual_distance / cruising_speed_kmh) + 1.0

    # Format hasil
    return round(flight_time, 2)


print(calculate_cargo_travel_time((41.8781, -87.6298), (-33.8688, 151.2093)))
```

### Menyiapkan agent

Untuk model provider, kita menggunakan Together AI, salah satu [inference providers baru di Hub](https://huggingface.co/blog/inference-providers)!

GoogleSearchTool menggunakan [Serper API](https://serper.dev) untuk mencari di web, jadi kamu perlu menyiapkan env variable `SERPAPI_API_KEY` dan meneruskan `provider="serpapi"`, atau menyiapkan `SERPER_API_KEY` dan meneruskan `provider=serper`.

Kalau kamu tidak punya setup provider Serp API apa pun, kamu bisa memakai `DuckDuckGoSearchTool`, tetapi ingat bahwa tool ini punya rate limit.

### ✌️ Membagi tugas di antara dua agents

Struktur multi-agent memungkinkan kita memisahkan memories untuk sub-tasks yang berbeda, dengan dua manfaat besar:
- Setiap agent lebih fokus pada tugas intinya, sehingga performanya lebih baik
- Memisahkan memories mengurangi jumlah input token di setiap langkah, sehingga latency dan biaya ikut turun.

Mari buat tim dengan web search agent khusus yang dikelola oleh agent lain.

Manager agent perlu memiliki kemampuan plotting untuk menulis laporan akhirnya. Jadi, kita beri akses ke imports tambahan, termasuk `plotly`, serta `geopandas` + `shapely` untuk spatial plotting.

```python
model = InferenceClientModel(
    "Qwen/Qwen2.5-Coder-32B-Instruct", provider="together", max_tokens=8096
)

web_agent = CodeAgent(
    model=model,
    tools=[
        GoogleSearchTool(provider="serper"),
        VisitWebpageTool(),
        calculate_cargo_travel_time,
    ],
    name="web_agent",
    description="Browses the web to find information",
    verbosity_level=0,
    max_steps=10,
)
```

Manager agent perlu melakukan pekerjaan reasoning yang lebih berat.

Jadi, kita memberinya model yang lebih kuat, [DeepSeek-R1](https://huggingface.co/deepseek-ai/DeepSeek-R1), dan menambahkan `planning_interval`.

```python
from smolagents.utils import encode_image_base64, make_image_url
from smolagents import OpenAIServerModel


def check_reasoning_and_plot(final_answer, agent_memory):
    multimodal_model = OpenAIServerModel("gpt-4o", max_tokens=8096)
    filepath = "saved_map.png"
    assert os.path.exists(filepath), "Make sure to save the plot under saved_map.png!"
    image = Image.open(filepath)
    prompt = (
        f"Here is a user-given task and the agent steps: {agent_memory.get_succinct_steps()}. Now here is the plot that was made."
        "Please check that the reasoning process and plot are correct: do they correctly answer the given task?"
        "First list reasons why yes/no, then write your final decision: PASS in caps lock if it is satisfactory, FAIL if it is not."
        "Don't be harsh: if the plot mostly solves the task, it should pass."
        "To pass, a plot should be made using px.scatter_map and not any other method (scatter_map looks nicer)."
    )
    messages = [
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": prompt,
                },
                {
                    "type": "image_url",
                    "image_url": {"url": make_image_url(encode_image_base64(image))},
                },
            ],
        }
    ]
    output = multimodal_model(messages).content
    print("Feedback: ", output)
    if "FAIL" in output:
        raise Exception(output)
    return True


manager_agent = CodeAgent(
    model=InferenceClientModel("deepseek-ai/DeepSeek-R1", provider="together", max_tokens=8096),
    tools=[calculate_cargo_travel_time],
    managed_agents=[web_agent],
    additional_authorized_imports=[
        "geopandas",
        "plotly",
        "shapely",
        "json",
        "pandas",
        "numpy",
    ],
    planning_interval=5,
    verbosity_level=2,
    final_answer_checks=[check_reasoning_and_plot],
    max_steps=15,
)
```
