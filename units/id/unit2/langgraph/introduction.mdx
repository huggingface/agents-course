# Pengantar `LangGraph`

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit2/LangGraph/LangGraph.png" alt="Thumbnail Unit 2.3"/>

Selamat datang di bagian berikutnya dari perjalanan kita. Di sini, kamu akan belajar **cara membuat aplikasi** dengan framework [`LangGraph`](https://github.com/langchain-ai/langgraph), yang dirancang untuk membantumu menyusun dan mengorkestrasi workflow LLM yang kompleks.

`LangGraph` adalah framework yang memungkinkanmu membangun aplikasi **production-ready** dengan memberimu tools untuk **mengontrol** flow agent.
