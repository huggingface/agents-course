## Langkah 1: Definisikan State

Mari definisikan informasi apa saja yang perlu dilacak Alfred selama workflow pemrosesan email:

```python
class EmailState(TypedDict):
    # Email yang sedang diproses
    email: Dict[str, Any]  # Berisi subject, sender, body, etc.

    # Kategori email (inquiry, complaint, etc.)
    email_category: Optional[str]

    # Alasan email ditandai sebagai spam
    spam_reason: Optional[str]

    # Analisis dan keputusan
    is_spam: Optional[bool]

    # Pembuatan respons
    email_draft: Optional[str]

    # Metadata pemrosesan
    messages: List[Dict[str, Any]]  # Lacak percakapan dengan LLM untuk analisis
```

> 💡 **Kiat:** Buat state cukup lengkap untuk melacak semua informasi penting, tetapi hindari membuatnya terlalu penuh dengan detail yang tidak perlu.

## Langkah 2: Definisikan Nodes

Sekarang, mari buat fungsi pemrosesan yang akan menjadi nodes kita:

```python
# Inisialisasi LLM kita
model = ChatOpenAI(temperature=0)

def read_email(state: EmailState):
    """Alfred reads and logs the incoming email"""
    email = state["email"]

    # Di sini kita bisa melakukan preprocessing awal
    print(f"Alfred is processing an email from {email['sender']} with subject: {email['subject']}")

    # Tidak ada perubahan state yang dibutuhkan di sini
    return {}

def classify_email(state: EmailState):
    """Alfred uses an LLM to determine if the email is spam or legitimate"""
    email = state["email"]

    # Siapkan prompt untuk LLM
    prompt = f"""
    As Alfred the butler, analyze this email and determine if it is spam or legitimate.

    Email:
    From: {email['sender']}
    Subject: {email['subject']}
    Body: {email['body']}

    First, determine if this email is spam. If it is spam, explain why.
    If it is legitimate, categorize it (inquiry, complaint, thank you, etc.).
    """

    # Panggil LLM
    messages = [HumanMessage(content=prompt)]
    response = model.invoke(messages)

    # Logic sederhana untuk parse respons (di aplikasi nyata, parsing sebaiknya lebih robust)
    response_text = response.content.lower()
    is_spam = "spam" in response_text and "not spam" not in response_text

    # Ambil alasan jika email adalah spam
    spam_reason = None
    if is_spam and "reason:" in response_text:
        spam_reason = response_text.split("reason:")[1].strip()

    # Tentukan kategori jika legitimate
    email_category = None
    if not is_spam:
        categories = ["inquiry", "complaint", "thank you", "request", "information"]
        for category in categories:
            if category in response_text:
                email_category = category
                break

    # Perbarui messages untuk pelacakan
    new_messages = state.get("messages", []) + [
        {"role": "user", "content": prompt},
        {"role": "assistant", "content": response.content}
    ]

    # Kembalikan update state
    return {
        "is_spam": is_spam,
        "spam_reason": spam_reason,
        "email_category": email_category,
        "messages": new_messages
    }

def handle_spam(state: EmailState):
    """Alfred discards spam email with a note"""
    print(f"Alfred has marked the email as spam. Reason: {state['spam_reason']}")
    print("The email has been moved to the spam folder.")

    # Kita selesai memproses email ini
    return {}

def draft_response(state: EmailState):
    """Alfred drafts a preliminary response for legitimate emails"""
    email = state["email"]
    category = state["email_category"] or "general"

    # Siapkan prompt untuk LLM
    prompt = f"""
    As Alfred the butler, draft a polite preliminary response to this email.

    Email:
    From: {email['sender']}
    Subject: {email['subject']}
    Body: {email['body']}

    This email has been categorized as: {category}

    Draft a brief, professional response that Mr. Hugg can review and personalize before sending.
    """

    # Panggil LLM
    messages = [HumanMessage(content=prompt)]
    response = model.invoke(messages)

    # Perbarui messages untuk pelacakan
    new_messages = state.get("messages", []) + [
        {"role": "user", "content": prompt},
        {"role": "assistant", "content": response.content}
    ]

    # Kembalikan update state
    return {
        "email_draft": response.content,
        "messages": new_messages
    }

def notify_mr_hugg(state: EmailState):
    """Alfred notifies Mr. Hugg about the email and presents the draft response"""
    email = state["email"]

    print("\n" + "="*50)
    print(f"Sir, you've received an email from {email['sender']}.")
    print(f"Subject: {email['subject']}")
    print(f"Category: {state['email_category']}")
    print("\nI've prepared a draft response for your review:")
    print("-"*50)
    print(state["email_draft"])
    print("="*50 + "\n")

    # Kita selesai memproses email ini
    return {}
```

## Langkah 3: Definisikan Logika Routing

Kita membutuhkan fungsi untuk menentukan jalur mana yang diambil setelah klasifikasi:

```python
def route_email(state: EmailState) -> str:
    """Determine the next step based on spam classification"""
    if state["is_spam"]:
        return "spam"
    else:
        return "legitimate"
```

> 💡 **Catatan:** Fungsi routing ini dipanggil oleh LangGraph untuk menentukan edge mana yang diikuti setelah node klasifikasi. Nilai return-nya harus cocok dengan salah satu key pada mapping conditional edges kita.

## Langkah 4: Buat StateGraph dan Definisikan Edges

Sekarang kita hubungkan semuanya:

```python
# Buat graph
email_graph = StateGraph(EmailState)

# Tambahkan nodes
email_graph.add_node("read_email", read_email)
email_graph.add_node("classify_email", classify_email)
email_graph.add_node("handle_spam", handle_spam)
email_graph.add_node("draft_response", draft_response)
email_graph.add_node("notify_mr_hugg", notify_mr_hugg)

# Mulai edges
email_graph.add_edge(START, "read_email")
# Tambahkan edges - mendefinisikan flow
email_graph.add_edge("read_email", "classify_email")

# Tambahkan conditional branching dari classify_email
email_graph.add_conditional_edges(
    "classify_email",
    route_email,
    {
        "spam": "handle_spam",
        "legitimate": "draft_response"
    }
)

# Tambahkan edges akhir
email_graph.add_edge("handle_spam", END)
email_graph.add_edge("draft_response", "notify_mr_hugg")
email_graph.add_edge("notify_mr_hugg", END)

# Compile graph
compiled_graph = email_graph.compile()
```

Perhatikan bagaimana kita memakai node khusus `END` yang disediakan LangGraph. Node ini menandai terminal states tempat workflow selesai.

## Langkah 6: Memeriksa Mail Sorting Agent dengan Langfuse 📡

Saat Alfred melakukan fine-tune pada Mail Sorting Agent, ia mulai lelah men-debug run-nya. Agents memang cenderung tidak prediktabel dan sulit diperiksa. Namun, karena ia ingin membangun Spam Detection Agent terbaik dan men-deploy-nya ke production, ia membutuhkan traceability yang kuat untuk monitoring dan analisis ke depan.

Untuk itu, Alfred bisa memakai observability tool seperti [Langfuse](https://langfuse.com/) untuk melakukan trace dan monitor agent.

Pertama, kita pip install Langfuse:
```python
%pip install -q langfuse
```

Kedua, kita pip install Langchain (LangChain diperlukan karena kita memakai LangFuse):
```python
%pip install langchain
```

Berikutnya, kita tambahkan Langfuse API keys dan alamat host sebagai environment variables. Kamu bisa mendapatkan kredensial Langfuse dengan mendaftar ke [Langfuse Cloud](https://cloud.langfuse.com) atau [self-host Langfuse](https://langfuse.com/self-hosting).

```python
import os

# Dapatkan keys untuk project-mu dari halaman project settings: https://cloud.langfuse.com
os.environ["LANGFUSE_PUBLIC_KEY"] = "pk-lf-..."
os.environ["LANGFUSE_SECRET_KEY"] = "sk-lf-..."
os.environ["LANGFUSE_HOST"] = "https://cloud.langfuse.com" # 🇪🇺 region EU
# os.environ["LANGFUSE_HOST"] = "https://us.cloud.langfuse.com" # 🇺🇸 region US
```

Lalu, kita konfigurasi [Langfuse `callback_handler`](https://langfuse.com/docs/integrations/langchain/tracing#add-langfuse-to-your-langchain-application) dan melakukan instrumentasi agent dengan menambahkan `langfuse_callback` ke invocation graph: `config={"callbacks": [langfuse_handler]}`.

```python
from langfuse.langchain import CallbackHandler

# Inisialisasi Langfuse CallbackHandler untuk LangGraph/Langchain (tracing)
langfuse_handler = CallbackHandler()

# Proses email legitimate
legitimate_result = compiled_graph.invoke(
    input={"email": legitimate_email, "is_spam": None, "spam_reason": None, "email_category": None, "draft_response": None, "messages": []},
    config={"callbacks": [langfuse_handler]}
)
```

Sekarang Alfred sudah terhubung 🔌! Runs dari LangGraph dicatat di Langfuse, sehingga ia punya visibilitas penuh ke perilaku agent. Dengan setup ini, ia siap meninjau runs sebelumnya dan menyempurnakan Mail Sorting Agent lebih jauh.
