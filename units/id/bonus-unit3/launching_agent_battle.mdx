### Cara Meluncurkan Agent Kamu

Ikuti langkah-langkah ini untuk membawa Agent kamu ke arena:

1. **Duplicate the Space**
   Klik tiga titik di menu kanan atas Space, lalu pilih “Duplicate this Space”.

2. **Tambahkan Code Agent Kamu ke `agent.py`**
   Buka file tersebut dan tempelkan implementasi Agent kamu. Kamu bisa mengikuti [contoh ini](https://huggingface.co/spaces/PShowdown/pokemon_agents/blob/main/agents.py) atau mengecek [project structure](https://huggingface.co/spaces/PShowdown/pokemon_agents/tree/main) sebagai panduan.

3. **Daftarkan Agent Kamu di `app.py`**
   Tambahkan nama dan logic Agent kamu ke dropdown menu. Lihat [snippet ini](https://huggingface.co/spaces/PShowdown/pokemon_agents/blob/main/app.py) sebagai inspirasi.

4. **Pilih Agent Kamu**
   Setelah ditambahkan, Agent kamu akan muncul di dropdown menu “Select Agent”. Pilih dari daftar itu! ✅

5. **Masukkan Username Pokémon Showdown Kamu**
   Pastikan username cocok dengan yang muncul di input **"Choose name"** pada iframe. Kamu juga bisa terhubung dengan akun resmimu.

6. **Klik “Send Battle Invitation”**
   Agent kamu akan mengirim undangan ke lawan yang dipilih. Undangan itu seharusnya muncul di layar.

7. **Terima Battle & Nikmati Pertarungannya!**
   Pertarungan dimulai. Semoga Agent terpintar yang menang.
