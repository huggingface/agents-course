Sekarang kita sudah membangun semua komponen yang dibutuhkan Alfred, saatnya menyatukan semuanya menjadi agent lengkap yang bisa membantu menjadi tuan rumah gala mewah kita.

Di bagian ini, kita akan menggabungkan tools untuk retrieval informasi tamu, web search, informasi cuaca, dan statistik Hub menjadi satu agent yang powerful.

Alih-alih mengimplementasikan ulang semua tools yang sudah kita buat di bagian sebelumnya, kita akan mengimpornya dari module masing-masing yang sudah kita simpan di file `tools.py` dan `retriever.py`.

```python
from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages
from langchain_core.messages import AnyMessage, HumanMessage, AIMessage
from langgraph.prebuilt import ToolNode
from langgraph.graph import START, StateGraph
from langgraph.prebuilt import tools_condition
from langchain_huggingface import HuggingFaceEndpoint, ChatHuggingFace

from tools import DuckDuckGoSearchRun, weather_info_tool, hub_stats_tool
from retriever import guest_info_tool
```

Sekarang, mari gabungkan semua tools ini menjadi satu agent:

```python
# Inisialisasi web search tool
search_tool = DuckDuckGoSearchRun()

# Buat chat interface, termasuk tools
llm = HuggingFaceEndpoint(
    repo_id="Qwen/Qwen2.5-Coder-32B-Instruct",
    huggingfacehub_api_token=HUGGINGFACEHUB_API_TOKEN,
)

chat = ChatHuggingFace(llm=llm, verbose=True)
tools = [guest_info_tool, search_tool, weather_info_tool, hub_stats_tool]
chat_with_tools = chat.bind_tools(tools)

# Buat AgentState dan graph Agent
class AgentState(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]

def assistant(state: AgentState):
    return {
        "messages": [chat_with_tools.invoke(state["messages"])],
    }

## Graph
builder = StateGraph(AgentState)

# Definisikan node: bagian ini yang menjalankan pekerjaan
builder.add_node("assistant", assistant)
builder.add_node("tools", ToolNode(tools))

# Definisikan edge: bagian ini menentukan bagaimana control flow bergerak
builder.add_edge(START, "assistant")
builder.add_conditional_edges(
    "assistant",
    # Jika pesan terbaru membutuhkan tool, arahkan ke tools
    # Jika tidak, berikan respons langsung
    tools_condition,
)
builder.add_edge("tools", "assistant")
alfred = builder.compile()
```

## Fitur Lanjutan: Conversation Memory

Untuk membuat Alfred semakin membantu selama gala, kita bisa mengaktifkan conversation memory agar ia mengingat interaksi sebelumnya:

<hfoptions id="agents-frameworks">
<hfoption id="smolagents">

```python
# Buat Alfred dengan conversation memory
alfred_with_memory = CodeAgent(
    tools=[guest_info_tool, weather_info_tool, hub_stats_tool, search_tool],
    model=model,
    add_base_tools=True,
    planning_interval=3
)

# Interaksi pertama
response1 = alfred_with_memory.run("Tell me about Lady Ada Lovelace.")
print("🎩 Alfred's First Response:")
print(response1)

# Interaksi kedua (merujuk ke interaksi pertama)
response2 = alfred_with_memory.run("What projects is she currently working on?", reset=False)
print("🎩 Alfred's Second Response:")
print(response2)
```

Perhatikan bahwa ketiga pendekatan agent ini tidak mengaitkan memory langsung dengan agent. Apakah ada alasan khusus di balik pilihan desain ini 🧐?
* smolagents: Memory tidak dipertahankan di antara execution run yang berbeda; kamu harus menyatakannya secara eksplisit menggunakan `reset=False`.
* LlamaIndex: Membutuhkan penambahan context object secara eksplisit untuk manajemen memory dalam sebuah run.
* LangGraph: Menawarkan opsi untuk mengambil pesan sebelumnya atau menggunakan komponen khusus [MemorySaver](https://langchain-ai.github.io/langgraph/tutorials/introduction/#part-3-adding-memory-to-the-chatbot).
