## Membuat Custom Tool Informasi Cuaca untuk Menjadwalkan Kembang Api

Gala yang sempurna akan memiliki kembang api di langit yang cerah, jadi kita perlu memastikan kembang api tidak dibatalkan karena cuaca buruk.

Mari buat custom tool yang bisa digunakan untuk memanggil API cuaca eksternal dan mendapatkan informasi cuaca untuk lokasi tertentu.

> [!TIP]
> Demi kesederhanaan, kita menggunakan dummy weather API untuk contoh ini. Jika ingin menggunakan API cuaca sungguhan, kamu bisa mengimplementasikan weather tool yang menggunakan OpenWeatherMap API, seperti di <a href="../../unit1/tutorial">Unit 1</a>.

<hfoptions id="agents-frameworks">
<hfoption id="smolagents">

```python
from smolagents import Tool
import random

class WeatherInfoTool(Tool):
    name = "weather_info"
    description = "Fetches dummy weather information for a given location."
    inputs = {
        "location": {
            "type": "string",
            "description": "The location to get weather information for."
        }
    }
    output_type = "string"

    def forward(self, location: str):
        # Data cuaca dummy
        weather_conditions = [
            {"condition": "Rainy", "temp_c": 15},
            {"condition": "Clear", "temp_c": 25},
            {"condition": "Windy", "temp_c": 20}
        ]
        # Pilih kondisi cuaca secara acak
        data = random.choice(weather_conditions)
        return f"Weather in {location}: {data['condition']}, {data['temp_c']}°C"

# Inisialisasi tool
weather_info_tool = WeatherInfoTool()
```

## Membuat Hub Stats Tool untuk AI Builders Berpengaruh

Para tokoh penting AI builders akan hadir di gala. Alfred ingin membuat mereka terkesan dengan membahas models, datasets, dan spaces paling populer milik mereka. Kita akan membuat tool untuk mengambil statistik model dari Hugging Face Hub berdasarkan username.

<hfoptions id="agents-frameworks">
<hfoption id="smolagents">

```python
from smolagents import Tool
from huggingface_hub import list_models

class HubStatsTool(Tool):
    name = "hub_stats"
    description = "Fetches the most downloaded model from a specific author on the Hugging Face Hub."
    inputs = {
        "author": {
            "type": "string",
            "description": "The username of the model author/organization to find models from."
        }
    }
    output_type = "string"

    def forward(self, author: str):
        try:
            # Daftar model dari author tertentu, diurutkan berdasarkan jumlah unduhan
            models = list(list_models(author=author, sort="downloads", direction=-1, limit=1))

            if models:
                model = models[0]
                return f"The most downloaded model by {author} is {model.id} with {model.downloads:,} downloads."
            else:
                return f"No models found for author {author}."
        except Exception as e:
            return f"Error fetching models for {author}: {str(e)}"

# Inisialisasi tool
hub_stats_tool = HubStatsTool()

# Contoh penggunaan
print(hub_stats_tool("facebook")) # Contoh: Ambil model yang paling banyak diunduh dari Facebook
```

Output yang diharapkan:

```
The most downloaded model by facebook is facebook/esmfold_v1 with 12,544,550 downloads.
```

## Mengintegrasikan Tools dengan Alfred

Sekarang kita sudah memiliki semua tools, mari integrasikan semuanya ke dalam agent Alfred:

<hfoptions id="agents-frameworks">
<hfoption id="smolagents">

```python
from smolagents import CodeAgent, InferenceClientModel

# Inisialisasi model Hugging Face
model = InferenceClientModel()

# Buat Alfred dengan semua tools
alfred = CodeAgent(
    tools=[search_tool, weather_info_tool, hub_stats_tool],
    model=model
)

# Contoh query yang mungkin diterima Alfred selama gala
response = alfred.run("What is Facebook and what's their most popular model?")

print("🎩 Alfred's Response:")
print(response)
```

Output yang diharapkan:

```
🎩 Alfred's Response:
Facebook adalah situs jejaring sosial tempat pengguna bisa terhubung, berbagi informasi, dan berinteraksi dengan orang lain. Model yang paling banyak diunduh dari Facebook di Hugging Face Hub adalah ESMFold_v1.
```

<hfoption id="langgraph">

```python
from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages
from langchain_core.messages import AnyMessage, HumanMessage, AIMessage
from langgraph.prebuilt import ToolNode
from langgraph.graph import START, StateGraph
from langgraph.prebuilt import tools_condition
from langchain_huggingface import HuggingFaceEndpoint, ChatHuggingFace

# Buat chat interface, termasuk tools
llm = HuggingFaceEndpoint(
    repo_id="Qwen/Qwen2.5-Coder-32B-Instruct",
    huggingfacehub_api_token=HUGGINGFACEHUB_API_TOKEN,
)

chat = ChatHuggingFace(llm=llm, verbose=True)
tools = [search_tool, weather_info_tool, hub_stats_tool]
chat_with_tools = chat.bind_tools(tools)

# Buat AgentState dan graph Agent
class AgentState(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]

def assistant(state: AgentState):
    return {
        "messages": [chat_with_tools.invoke(state["messages"])],
    }

## Graph
builder = StateGraph(AgentState)

# Definisikan node: bagian ini yang menjalankan pekerjaan
builder.add_node("assistant", assistant)
builder.add_node("tools", ToolNode(tools))

# Definisikan edge: bagian ini menentukan bagaimana control flow bergerak
builder.add_edge(START, "assistant")
builder.add_conditional_edges(
    "assistant",
    # Jika pesan terbaru membutuhkan tool, arahkan ke tools
    # Jika tidak, berikan respons langsung
    tools_condition,
)
builder.add_edge("tools", "assistant")
alfred = builder.compile()

messages = [HumanMessage(content="Who is Facebook and what's their most popular model?")]
response = alfred.invoke({"messages": messages})

print("🎩 Alfred's Response:")
print(response['messages'][-1].content)
```

Output yang diharapkan:

```
🎩 Alfred's Response:
Facebook adalah perusahaan media sosial yang dikenal melalui situs jejaring sosial Facebook, serta layanan lain seperti Instagram dan WhatsApp. Model yang paling banyak diunduh dari Facebook di Hugging Face Hub adalah facebook/esmfold_v1 dengan 13.202.321 unduhan.
```
