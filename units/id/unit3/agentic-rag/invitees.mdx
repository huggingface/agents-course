# Membuat Tool RAG untuk Cerita Tamu


Alfred, agent tepercaya kita, sedang menyiapkan gala paling megah abad ini. Agar acara berjalan lancar, Alfred membutuhkan akses cepat ke informasi terbaru tentang setiap tamu. Mari bantu Alfred dengan membuat tool Retrieval-Augmented Generation (RAG) khusus, yang didukung oleh dataset kustom kita.

## Mengapa RAG untuk Gala?

Bayangkan Alfred berbaur dengan para tamu dan harus mengingat detail spesifik tentang setiap orang dengan cepat. LLM tradisional bisa kesulitan dengan tugas ini karena:

1. Daftar tamu bersifat spesifik untuk acaramu dan tidak ada dalam data training model
2. Informasi tamu bisa berubah atau sering diperbarui
3. Alfred perlu mengambil detail yang presisi, seperti alamat email

Di sinilah Retrieval Augmented Generation (RAG) sangat berguna! Dengan menggabungkan sistem retrieval dan LLM, Alfred bisa mengakses informasi akurat dan up-to-date tentang para tamumu saat dibutuhkan.

### Langkah 2: Buat Retriever Tool

Sekarang, mari buat custom tool yang bisa digunakan Alfred untuk mencari informasi tamu.

<hfoptions id="agents-frameworks">
<hfoption id="smolagents">

Kita akan menggunakan `BM25Retriever` dari module `langchain_community.retrievers` untuk membuat retriever tool.

> [!TIP]
> <code>BM25Retriever</code> adalah titik awal yang bagus untuk retrieval, tetapi untuk semantic search yang lebih lanjutan, kamu bisa mempertimbangkan retriever berbasis embedding seperti yang tersedia di <a href="https://www.sbert.net/">sentence-transformers</a>.

```python
from smolagents import Tool
from langchain_community.retrievers import BM25Retriever

class GuestInfoRetrieverTool(Tool):
    name = "guest_info_retriever"
    description = "Retrieves detailed information about gala guests based on their name or relation."
    inputs = {
        "query": {
            "type": "string",
            "description": "The name or relation of the guest you want information about."
        }
    }
    output_type = "string"

    def __init__(self, docs):
        self.is_initialized = False
        self.retriever = BM25Retriever.from_documents(docs)

    def forward(self, query: str):
        results = self.retriever.invoke(query)
        if results:
            return "\n\n".join([doc.page_content for doc in results[:3]])
        else:
            return "No matching guest information found."

# Inisialisasi tool
guest_info_tool = GuestInfoRetrieverTool(docs)
```

Mari pahami tool ini langkah demi langkah:
- `name` dan `description` membantu agent memahami kapan dan bagaimana menggunakan tool ini
- `inputs` mendefinisikan parameter yang diharapkan tool (dalam kasus ini, search query)
- Kita menggunakan `BM25Retriever`, algoritma text retrieval yang powerful dan tidak membutuhkan embeddings
- Method `forward` memproses query dan mengembalikan informasi tamu yang paling relevan

```python
from typing import TypedDict, Annotated
from langgraph.graph.message import add_messages
from langchain_core.messages import AnyMessage, HumanMessage, AIMessage
from langgraph.prebuilt import ToolNode
from langgraph.graph import START, StateGraph
from langgraph.prebuilt import tools_condition
from langchain_huggingface import HuggingFaceEndpoint, ChatHuggingFace

# Buat chat interface, termasuk tools
llm = HuggingFaceEndpoint(
    repo_id="Qwen/Qwen2.5-Coder-32B-Instruct",
    huggingfacehub_api_token=HUGGINGFACEHUB_API_TOKEN,
)

chat = ChatHuggingFace(llm=llm, verbose=True)
tools = [guest_info_tool]
chat_with_tools = chat.bind_tools(tools)

# Buat AgentState dan graph Agent
class AgentState(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]

def assistant(state: AgentState):
    return {
        "messages": [chat_with_tools.invoke(state["messages"])],
    }

## Graph
builder = StateGraph(AgentState)

# Definisikan node: bagian ini yang menjalankan pekerjaan
builder.add_node("assistant", assistant)
builder.add_node("tools", ToolNode(tools))

# Definisikan edge: bagian ini menentukan bagaimana control flow bergerak
builder.add_edge(START, "assistant")
builder.add_conditional_edges(
    "assistant",
    # Jika pesan terbaru membutuhkan tool, arahkan ke tools
    # Jika tidak, berikan respons langsung
    tools_condition,
)
builder.add_edge("tools", "assistant")
alfred = builder.compile()

messages = [HumanMessage(content="Tell me about our guest named 'Lady Ada Lovelace'.")]
response = alfred.invoke({"messages": messages})

print("🎩 Alfred's Response:")
print(response['messages'][-1].content)
```

Output yang diharapkan:

```
🎩 Alfred's Response:
Lady Ada Lovelace adalah matematikawan terhormat dan pionir dalam komputasi, sering dirayakan sebagai programmer komputer pertama berkat karyanya pada Analytical Engine milik Charles Babbage.
```

Yang terjadi pada langkah terakhir ini:
- Kita menginisialisasi model Hugging Face menggunakan class `HuggingFaceEndpoint`. Kita juga membuat chat interface dan menambahkan tools.
- Kita membuat agent kita (Alfred) sebagai `StateGraph`, yang menggabungkan 2 node (`assistant`, `tools`) menggunakan edge
- Kita meminta Alfred mengambil informasi tentang tamu bernama "Lady Ada Lovelace"
