# Pengantar Agents

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit1/thumbnail.jpg" alt="Thumbnail"/>

Selamat datang di unit pertama ini, tempat **kamu akan membangun fondasi yang kuat dalam fundamental AI Agents**, termasuk:

- **Memahami Agents**
  - Apa itu Agent, dan bagaimana cara kerjanya?
  - Bagaimana Agents membuat keputusan menggunakan reasoning dan planning?

- **Peran LLMs (Large Language Models) dalam Agents**
  - Bagaimana LLMs berperan sebagai "otak" di balik Agent.
  - Bagaimana LLMs menyusun percakapan melalui sistem Messages.

- **Tools dan Actions**
  - Bagaimana Agents menggunakan tools eksternal untuk berinteraksi dengan environment.
  - Cara membangun dan mengintegrasikan tools untuk Agent-mu.

- **Workflow Agent:**
  - *Think* → *Act* → *Observe*.

Setelah mengeksplorasi topik-topik ini, **kamu akan membangun Agent pertamamu** menggunakan `smolagents`!

Agent-mu, bernama Alfred, akan menangani tugas sederhana dan mendemonstrasikan cara menerapkan konsep-konsep ini dalam praktik.

Kamu bahkan akan belajar cara **mempublikasikan Agent-mu di Hugging Face Spaces**, sehingga kamu bisa membagikannya kepada teman dan kolega.

Terakhir, di akhir Unit ini, kamu akan mengikuti quiz. Jika lulus, kamu akan **mendapatkan sertifikasi kursus pertamamu**: 🎓 Certificate of Fundamentals of Agents.
