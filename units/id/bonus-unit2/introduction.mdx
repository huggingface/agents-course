# Observability & Evaluation AI Agent

![Thumbnail Bonus Unit 2](https://langfuse.com/images/cookbook/huggingface-agent-course/agent-observability-and-evaluation.png)

Selamat datang di **Bonus Unit 2**! Di bab ini, kamu akan mempelajari strategi yang lebih advanced untuk mengamati, mengevaluasi, dan memperbaiki performa agents.

---

## 📚 Kapan Sebaiknya Saya Mengerjakan Bonus Unit Ini?

Bonus unit ini cocok kalau kamu:
- **Mengembangkan dan men-deploy AI Agents:** Kamu ingin memastikan agents berjalan andal di production.
- **Butuh insight yang detail:** Kamu ingin mendiagnosis masalah, memperbaiki performa, atau memahami cara kerja internal agent.
- **Ingin mengurangi beban operasional:** Dengan memantau cost, latency, dan detail execution agent, kamu bisa mengelola resource dengan lebih efisien.
- **Mencari perbaikan berkelanjutan:** Kamu ingin menggabungkan feedback user secara real-time dan automated evaluation ke aplikasi AI.

Singkatnya, ini untuk siapa pun yang ingin membawa agents ke hadapan user sungguhan.

---

## 🤓 Yang Akan Kamu Pelajari

Di unit ini, kamu akan belajar:
- **Melakukan instrumentation pada agent:** Pelajari cara mengintegrasikan observability tools melalui OpenTelemetry dengan framework *smolagents*.
- **Memantau metrics:** Lacak indikator performa seperti penggunaan token (cost), latency, dan error traces.
- **Mengevaluasi secara real-time:** Pahami teknik live evaluation, termasuk mengumpulkan feedback user dan menggunakan LLM-as-a-judge.
- **Analisis offline:** Gunakan benchmark datasets, misalnya GSM8K, untuk menguji dan membandingkan performa agent.

Di bagian berikutnya, kamu akan mempelajari dasar-dasar Agent Observability dan Evaluation. Setelah itu, waktunya melihat langsung cara kerjanya.
