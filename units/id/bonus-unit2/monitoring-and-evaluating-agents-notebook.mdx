## Online Evaluation

Di bagian sebelumnya, kita mempelajari perbedaan online dan offline evaluation. Sekarang, kita akan melihat cara memantau agent di production dan mengevaluasinya secara live.

### Metrics Umum yang Dilacak di Production

1. **Costs**: instrumentation smolagents menangkap penggunaan token, yang bisa kamu ubah menjadi perkiraan cost dengan menetapkan harga per token.
2. **Latency**: amati waktu yang dibutuhkan untuk menyelesaikan setiap langkah, atau seluruh run.
3. **User Feedback**: user bisa memberi feedback langsung (thumbs up/down) untuk membantu memperbaiki atau mengoreksi agent.
4. **LLM-as-a-Judge**: gunakan LLM terpisah untuk mengevaluasi output agent hampir secara real-time, misalnya mengecek toxicity atau correctness.

#### 3. Attributes Tambahan

Kamu juga bisa mengirim attributes tambahan ke spans. Isinya bisa berupa `user_id`, `tags`, `session_id`, dan custom metadata. Memperkaya traces dengan detail seperti ini membantu analisis, debugging, dan pemantauan perilaku aplikasi di berbagai user atau session.

```python
from smolagents import (CodeAgent, DuckDuckGoSearchTool, InferenceClientModel)

search_tool = DuckDuckGoSearchTool()
agent = CodeAgent(
    tools=[search_tool],
    model=InferenceClientModel()
)

with langfuse.start_as_current_span(
    name="Smolagent-Trace",
    ) as span:

    # Jalankan aplikasi kamu di sini
    response = agent.run("What is the capital of Germany?")

    # Kirim attributes tambahan ke span
    span.update_trace(
        input="What is the capital of Germany?",
        output=response,
        user_id="smolagent-user-123",
        session_id="smolagent-session-123456789",
        tags=["city-question", "testing-agents"],
        metadata={"email": "user@langfuse.com"},
        )

# Flush events pada aplikasi berumur pendek
langfuse.flush()
```

#### 4. User Feedback

Jika agent kamu ditanamkan ke user interface, kamu bisa merekam feedback langsung dari user, seperti thumbs-up/down di chat UI. Berikut contoh penggunaan [Gradio](https://gradio.app/) untuk menyematkan chat dengan mekanisme feedback sederhana.

Pada potongan code di bawah, saat user mengirim pesan chat, kita menangkap trace di Langfuse. Jika user menyukai atau tidak menyukai jawaban terakhir, kita menambahkan score ke trace.

```python
import gradio as gr
from smolagents import (CodeAgent, InferenceClientModel)
from langfuse import get_client

langfuse = get_client()

model = InferenceClientModel()
agent = CodeAgent(tools=[], model=model, add_base_tools=True)

trace_id = None

def respond(prompt, history):
    with langfuse.start_as_current_span(
        name="Smolagent-Trace"):

        # Jalankan aplikasi kamu di sini
        output = agent.run(prompt)

        global trace_id
        trace_id = langfuse.get_current_trace_id()

    history.append({"role": "assistant", "content": str(output)})
    return history

def handle_like(data: gr.LikeData):
    # Untuk demonstrasi, kita petakan user feedback ke 1 (like) atau 0 (dislike)
    if data.liked:
        langfuse.create_score(
            value=1,
            name="user-feedback",
            trace_id=trace_id
        )
    else:
        langfuse.create_score(
            value=0,
            name="user-feedback",
            trace_id=trace_id
        )

with gr.Blocks() as demo:
    chatbot = gr.Chatbot(label="Chat", type="messages")
    prompt_box = gr.Textbox(placeholder="Type your message...", label="Your message")

    # Saat user menekan 'Enter' pada prompt, kita menjalankan 'respond'
    prompt_box.submit(
        fn=respond,
        inputs=[prompt_box, chatbot],
        outputs=chatbot
    )

    # Saat user mengklik tombol 'like' pada pesan, kita menjalankan 'handle_like'
    chatbot.like(handle_like, None, None)

demo.launch()
```

#### 5. LLM-as-a-Judge

LLM-as-a-Judge adalah cara lain untuk mengevaluasi output agent secara otomatis. Kamu bisa menyiapkan LLM call terpisah untuk menilai correctness, toxicity, style, atau kriteria lain yang penting untuk use case kamu.

**Workflow**:
1. Kamu mendefinisikan **Evaluation Template**, misalnya "Check if the text is toxic."
2. Setiap kali agent menghasilkan output, kamu mengirim output itu ke LLM "judge" dengan template tersebut.
3. Judge LLM merespons dengan rating atau label yang kamu log ke observability tool.

## Offline Evaluation

Online evaluation dibutuhkan untuk feedback live, tetapi kamu juga perlu **offline evaluation**, yaitu pemeriksaan sistematis sebelum atau selama development. Ini membantu menjaga kualitas dan reliability sebelum perubahan masuk ke production.

### Dataset Evaluation

Dalam offline evaluation, biasanya kamu:
1. Memiliki benchmark dataset, berisi pasangan prompt dan expected output
2. Menjalankan agent pada dataset tersebut
3. Membandingkan output dengan expected results atau menggunakan mekanisme scoring tambahan

Di bawah ini, kita mendemonstrasikan pendekatan tersebut dengan [GSM8K dataset](https://huggingface.co/datasets/openai/gsm8k), yang berisi pertanyaan matematika dan solusinya.

#### Menjalankan Agent pada Dataset

Kita mendefinisikan helper function `run_smolagent()` yang:
1. Memulai Langfuse span
2. Menjalankan agent pada prompt
3. Mencatat trace ID di Langfuse

Lalu, kita melakukan loop pada setiap item dataset, menjalankan agent, dan menautkan trace ke item dataset tersebut. Kalau perlu, kita juga bisa menambahkan evaluation score singkat.


```python
from opentelemetry.trace import format_trace_id
from smolagents import (CodeAgent, InferenceClientModel, LiteLLMModel)
from langfuse import get_client

langfuse = get_client()


# Contoh: menggunakan InferenceClientModel atau LiteLLMModel untuk mengakses model openai, anthropic, gemini, dan lainnya:
model = InferenceClientModel()

agent = CodeAgent(
    tools=[],
    model=model,
    add_base_tools=True
)

dataset_name = "gsm8k_dataset_huggingface"
current_run_name = "smolagent-notebook-run-01" # Mengidentifikasi evaluation run khusus ini

# Anggap 'run_smolagent' adalah function aplikasi kamu yang sudah di-instrument
def run_smolagent(question):
    with langfuse.start_as_current_generation(name="qna-llm-call") as generation:
        # Simulasikan LLM call
        result = agent.run(question)

        # Perbarui trace dengan input dan output
        generation.update_trace(
            input= question,
            output=result,
        )

        return result

dataset = langfuse.get_dataset(name=dataset_name) # Ambil dataset yang sudah diisi

for item in dataset.items:

    # Gunakan context manager item.run()
    with item.run(
        run_name=current_run_name,
        run_metadata={"model_provider": "Hugging Face", "temperature_setting": 0.7},
        run_description="Evaluation run for GSM8K dataset"
    ) as root_span: # root_span adalah root span dari trace baru untuk item dan run ini.
        # Semua operasi langfuse berikutnya dalam block ini menjadi bagian dari trace ini.

        # Panggil logika aplikasi kamu
        generated_answer = run_smolagent(question=item.input["text"])

        print(item.input)
```

Kamu bisa mengulangi proses ini dengan variasi:
- Models (OpenAI GPT, local LLM, dan lainnya)
- Tools (dengan search vs. tanpa search)
- Prompts (system messages yang berbeda)
