### Langkah 5: Menjalankan Model Secara Lokal dengan Ollama (jika kamu terkena batas Credit)

1. **Instal Ollama**

    Ikuti instruksi resmi <a href="https://ollama.com/download" target="_blank">di sini.</a>

2. **Pull model secara lokal**

    ```bash
    ollama pull qwen2:7b
    ```

    Di sini, kita melakukan pull untuk <a href="https://ollama.com/library/qwen2:7b" target="_blank">model qwen2:7b</a>. Cek <a href="https://ollama.com/search" target="_blank">website Ollama</a> untuk model lainnya.

3. **Jalankan Ollama di background (di satu terminal)**
    ``` bash
    ollama serve
    ```

    Jika kamu menemukan error "listen tcp 127.0.0.1:11434: bind: address already in use", gunakan perintah `sudo lsof -i :11434` untuk mengidentifikasi proses
    ID (PID) yang sedang menggunakan port ini. Jika proses tersebut adalah `ollama`, kemungkinan script instalasi di atas sudah menjalankan layanan ollama,
    jadi kamu bisa melewati perintah ini untuk memulai Ollama.

4. **Gunakan `LiteLLMModel`, bukan `InferenceClientModel`**

   Untuk menggunakan modul `LiteLLMModel` di `smolagents`, kamu bisa menjalankan perintah `pip` untuk menginstal modulnya.

``` bash
    pip install 'smolagents[litellm]'
```

``` python
    from smolagents import LiteLLMModel

    model = LiteLLMModel(
        model_id="ollama_chat/qwen2:7b",  # Atau coba model lain yang didukung Ollama
        api_base="http://127.0.0.1:11434",  # Server lokal default Ollama
        num_ctx=8192,
    )
```

5. **Mengapa ini bekerja?**
- Ollama menyajikan model secara lokal menggunakan API yang kompatibel dengan OpenAI di `http://localhost:11434`.
- `LiteLLMModel` dibuat untuk berkomunikasi dengan model apa pun yang mendukung format OpenAI chat/completion API.
- Artinya, kamu cukup mengganti `InferenceClientModel` dengan `LiteLLMModel` tanpa perlu mengubah kode lain. Ini solusi yang mulus dan plug-and-play.
