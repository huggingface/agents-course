## Tips menggunakan Discord secara efektif

### Cara bergabung ke server

Jika kamu belum terlalu familiar dengan Discord, kamu mungkin ingin membaca <a href="https://support.discord.com/hc/en-us/articles/360034842871-How-do-I-join-a-Server#h_01FSJF9GT2QJMS2PRAW36WNBS8" target="_blank">panduan</a> ini tentang cara bergabung ke server.

Berikut ringkasan singkat langkah-langkahnya:

1. Klik <a href="https://discord.gg/UrrTSsSyjb" target="_blank">Invite Link</a>.
2. Masuk dengan akun Discord-mu, atau buat akun jika belum punya.
3. Validasi bahwa kamu bukan AI agent!
4. Atur nickname dan avatar-mu.
5. Klik "Join Server".

### Cara menggunakan Discord secara efektif

Berikut beberapa tips untuk menggunakan Discord secara efektif:

- **Voice channels** tersedia, walaupun chat teks lebih sering digunakan.
- Kamu bisa memformat teks menggunakan **gaya markdown**, yang sangat berguna untuk menulis kode. Perlu diingat bahwa markdown tidak bekerja sebaik itu untuk tautan.
- Pertimbangkan untuk membuka thread untuk **percakapan panjang** agar diskusi tetap rapi.

Kami harap panduan ini membantumu! Jika ada pertanyaan, silakan tanya kami di Discord 🤗.
