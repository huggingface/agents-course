Selamat datang di topik paling menarik di AI saat ini: **Agents**!

Kursus gratis ini akan membawamu dalam perjalanan **dari pemula hingga ahli** untuk memahami, menggunakan, dan membangun AI agents.

Unit pertama ini akan membantumu onboarding:

- Mengenal **silabus kursus**.
- **Memilih jalur** yang akan kamu ambil (self-audit atau proses sertifikasi).
- **Mendapatkan informasi lebih lanjut tentang proses sertifikasi**.
- Mengenal tim di balik kursus ini.
- Membuat **akun Hugging Face**.
- **Mendaftar ke server Discord kami**, dan bertemu teman sekelas serta tim kami.

Mari kita mulai!

## Apa yang bisa kamu harapkan dari kursus ini? [[expect]]

Dalam kursus ini, kamu akan:

- 📖 Mempelajari AI Agents dalam **teori, desain, dan praktik.**
- 🧑‍💻 Belajar **menggunakan library AI Agent yang sudah mapan** seperti [smolagents](https://huggingface.co/docs/smolagents/en/index), [LlamaIndex](https://www.llamaindex.ai/), dan [LangGraph](https://langchain-ai.github.io/langgraph/).
- 💾 **Membagikan agents-mu** di Hugging Face Hub dan mengeksplorasi agents yang dibuat komunitas.
- 🏆 Berpartisipasi dalam tantangan tempat kamu akan **mengevaluasi agents-mu dibandingkan agents milik peserta lain.**
- 🎓 **Mendapatkan sertifikat penyelesaian** dengan menyelesaikan assignment.

Dan masih banyak lagi!

Di akhir kursus ini, kamu akan memahami **cara kerja Agents dan cara membangun Agents milikmu sendiri menggunakan library dan tools terbaru**.

Jangan lupa untuk **<a href="https://bit.ly/hf-learn-agents">mendaftar ke kursus ini!</a>**

(Kami menghargai privasimu. Kami mengumpulkan alamat emailmu agar dapat **mengirim tautan saat setiap Unit diterbitkan serta memberikan informasi tentang tantangan dan update**).

## Seperti apa bentuk kursus ini? [[course-look-like]]

Kursus ini terdiri dari:

- *Foundational Units*: tempat kamu mempelajari **konsep Agents secara teori**.
- *Hands-on*: tempat kamu akan belajar **menggunakan library AI Agent yang sudah mapan** untuk melatih agents-mu di environment unik. Bagian praktik langsung ini akan berbentuk **Hugging Face Spaces** dengan environment yang sudah dikonfigurasi.
- *Use case assignments*: tempat kamu menerapkan konsep yang sudah dipelajari untuk menyelesaikan masalah dunia nyata yang kamu pilih.
- *The Challenge*: kamu akan menempatkan agent-mu untuk bersaing dengan agents lain dalam sebuah tantangan. Akan ada juga [leaderboard](https://huggingface.co/spaces/agents-course/Students_leaderboard) agar kamu bisa membandingkan performa agents.

**Kursus ini adalah proyek hidup yang berkembang bersama feedback dan kontribusimu!** Jangan ragu untuk [membuka issues dan PRs di GitHub](https://github.com/huggingface/agents-course), serta ikut berdiskusi di server Discord kami.

Setelah menyelesaikan kursus, kamu juga bisa mengirim feedback [👉 menggunakan form ini](https://docs.google.com/forms/d/e/1FAIpQLSe9VaONn0eglax0uTwi29rIn4tM7H2sYmmybmG5jJNlE5v0xA/viewform?usp=dialog)

## Apa silabusnya? [[syllabus]]

Berikut **silabus umum untuk kursus ini**. Daftar topik yang lebih detail akan dirilis bersama setiap unit.

| Chapter | Topik | Deskripsi |
| :---- | :---- | :---- |
| 0 | Onboarding | Mempersiapkanmu dengan tools dan platform yang akan kamu gunakan. |
| 1 | Fundamental Agent | Menjelaskan Tools, Thoughts, Actions, Observations, dan formatnya. Menjelaskan LLMs, messages, special tokens, dan chat templates. Menunjukkan use case sederhana menggunakan fungsi python sebagai tools. |
| 2 | Frameworks | Memahami bagaimana fundamental diimplementasikan dalam library populer: smolagents, LangGraph, LLamaIndex |
| 3 | Use Cases | Mari membangun beberapa use case dunia nyata (terbuka untuk PRs 🤗 dari builder Agent berpengalaman) |
| 4 | Final Assignment | Membangun agent untuk benchmark terpilih dan membuktikan pemahamanmu tentang Agents di student leaderboard 🚀 |

Selain silabus utama, ada 3 bonus unit:
- *Bonus Unit 1*: Fine-tuning LLM untuk Function-calling
- *Bonus Unit 2*: Agent Observability and Evaluation
- *Bonus Unit 3*: Agents in Games with Pokemon

Misalnya, di Bonus Unit 3, kamu belajar membangun Agent-mu untuk memainkan pertarungan Pokemon 🥊.

## Proses Sertifikasi [[certification-process]]

<img src="https://huggingface.co/datasets/agents-course/course-images/resolve/main/en/unit0/three-paths.jpg" alt="Dua jalur" width="100%"/>

Kamu bisa memilih untuk mengikuti kursus ini *dalam mode audit*, atau mengerjakan aktivitas dan *mendapatkan salah satu dari dua sertifikat yang akan kami terbitkan*.

Jika kamu mengaudit kursus ini, kamu bisa mengikuti semua tantangan dan mengerjakan assignment jika mau, dan **kamu tidak perlu memberi tahu kami**.

Proses sertifikasi ini **sepenuhnya gratis**:

- *Untuk mendapatkan sertifikasi fundamental*: kamu perlu menyelesaikan Unit 1 kursus ini. Ini ditujukan untuk peserta yang ingin mengikuti perkembangan tren terbaru di Agents.
- *Untuk mendapatkan sertifikat penyelesaian*: kamu perlu menyelesaikan Unit 1, salah satu use case assignment yang akan kami usulkan selama kursus, dan final challenge.

Tidak ada **tenggat** untuk proses sertifikasi.
