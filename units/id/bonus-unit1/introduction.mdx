## Yang Akan Kamu Pelajari

1. **Function Calling**
   Cara LLM modern menyusun percakapan sehingga bisa memicu **Tools**.

2. **LoRA (Low-Rank Adaptation)**
   Metode fine-tuning yang **ringan dan efisien** untuk menekan beban komputasi dan storage. Dengan LoRA, training model besar bisa menjadi *lebih cepat, lebih murah, dan lebih mudah* di-deploy.

3. **Siklus Thought → Act → Observe** dalam model Function Calling
   Pendekatan sederhana untuk menyusun cara model memutuskan kapan dan bagaimana memanggil function, melacak langkah antara, serta menafsirkan hasil dari Tools atau API eksternal.

4. **Special Tokens Baru**
   Kita akan memperkenalkan **penanda khusus** yang membantu model membedakan:
   - reasoning “chain-of-thought” internal
   - function calls yang keluar dari model
   - respons yang kembali dari tools eksternal
