# Lalu Sekarang? Topik Apa yang Sebaiknya Dipelajari?

Agentic AI adalah bidang yang berkembang sangat cepat, dan memahami protokol dasar sangat penting untuk membangun sistem yang cerdas dan otonom.

Dua standar penting yang sebaiknya kamu kenali adalah:

- **Model Context Protocol (MCP)**
- **Agent-to-Agent Protocol (A2A)**

## 🔌 Model Context Protocol (MCP)

**Model Context Protocol (MCP)** dari Anthropic adalah standar terbuka yang memungkinkan AI models **terhubung dengan tools eksternal, sumber data, dan aplikasi** secara aman dan mulus, sehingga agents menjadi lebih mampu dan otonom.

Bayangkan MCP sebagai **adapter universal**, seperti port USB-C, yang memungkinkan AI models tersambung ke berbagai environment digital **tanpa membutuhkan integrasi khusus untuk masing-masing environment**.

MCP dengan cepat mendapatkan perhatian di industri, dengan perusahaan besar seperti OpenAI dan Google mulai mengadopsinya.

## 🤝 Agent-to-Agent (A2A) Protocol

Google telah mengembangkan **Agent-to-Agent (A2A) protocol** sebagai pendamping komplementer untuk Model Context Protocol (MCP) dari Anthropic.

Jika MCP menghubungkan agents ke tools eksternal, **A2A menghubungkan agents satu sama lain**, membuka jalan bagi sistem multi-agent yang kooperatif dan dapat bekerja bersama untuk menyelesaikan masalah kompleks.
